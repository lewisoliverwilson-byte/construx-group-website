Keyboard-first. API-first. No configuration overhead.

## Linear API — create issues programmatically

```ts
import { LinearClient } from '@linear/sdk';

const linear = new LinearClient({ apiKey: process.env.LINEAR_API_KEY });

// Create an issue from a Slack alert
async function createBugFromAlert(alert: SlackAlert) {
  const team = await linear.team('CONSTRUX');

  const issue = await linear.createIssue({
    teamId:      team.id,
    title:       `[Alert] ${alert.name}: ${alert.description}`,
    description: formatAlertMarkdown(alert),
    priority:    alert.severity === 'critical' ? 1 : 3,
    labelIds:    [await getLabelId('Bug'), await getLabelId('Alert')],
    assigneeId:  await getOncallUserId(),
  });

  return issue.issue;
}

// Query open high-priority issues
const { nodes: issues } = await linear.issues({
  filter: {
    team:     { key: { eq: 'CONSTRUX' } },
    priority: { lte: { eq: 2 } },
    state:    { type: { neq: 'completed' } },
  },
  orderBy: LinearDocument.PaginationOrderBy.Priority,
});

for (const issue of issues) {
  console.log(`[${issue.identifier}] ${issue.title} — ${issue.assignee?.name ?? 'unassigned'}`);
}
```

## Webhook — sync PR status to issues

```ts
// api/webhooks/github/route.ts
import { LinearClient } from '@linear/sdk';

const linear = new LinearClient({ apiKey: process.env.LINEAR_API_KEY! });

export async function POST(req: Request) {
  const event = await req.json();

  if (event.action === 'closed' && event.pull_request.merged) {
    const body: string = event.pull_request.body ?? '';

    // Extract Linear issue ID from PR description: "Fixes LIN-123"
    const match = body.match(/(?:fixes|closes|resolves)\s+(LIN-\d+)/i);
    if (!match) return Response.json({ ok: true });

    const identifier = match[1];
    const { nodes }  = await linear.issues({ filter: { identifier: { eq: identifier } } });
    const issue      = nodes[0];
    if (!issue) return Response.json({ ok: true });

    // Move to Done
    const doneState = await getDoneState(issue.team.id);
    await linear.updateIssue(issue.id, { stateId: doneState.id });
  }

  return Response.json({ ok: true });
}
```

## Cycles — sprint-like iterations without the ceremony

```ts
// Get the current cycle
const team = await linear.team('CONSTRUX');
const cycles = await team.cycles();
const activeCycle = cycles.nodes.find((c) => c.isActive);

if (activeCycle) {
  const issues = await activeCycle.issues();
  const byState = issues.nodes.reduce((acc, issue) => {
    const type = issue.state?.type ?? 'unknown';
    acc[type] = (acc[type] ?? 0) + 1;
    return acc;
  }, {} as Record<string, number>);

  console.log(`Cycle: ${activeCycle.name}`);
  console.log(`  completed: ${byState.completed ?? 0}`);
  console.log(`  in progress: ${byState.started ?? 0}`);
  console.log(`  backlog: ${byState.backlog ?? 0}`);
}
```

## Weekly digest — post to Slack

```ts
// Runs every Monday at 9am (Trigger.dev or Val Town cron)
async function weeklyLinearDigest() {
  const lastWeek = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000);

  const { nodes: completed } = await linear.issues({
    filter: {
      completedAt: { gte: { eq: lastWeek.toISOString() } },
      team:        { key: { eq: 'CONSTRUX' } },
    },
  });

  const { nodes: created } = await linear.issues({
    filter: {
      createdAt: { gte: { eq: lastWeek.toISOString() } },
      team:      { key: { eq: 'CONSTRUX' } },
    },
  });

  await postSlackMessage({
    text: `*Linear Weekly* — ${completed.length} closed, ${created.length} opened`,
    blocks: [
      {
        type: 'section',
        text: { type: 'mrkdwn', text: `Closed:\n${completed.map((i) => `• ${i.identifier}: ${i.title}`).join('\n')}` },
      },
    ],
  });
}
```

## Keyboard shortcuts — the ones worth learning

```
G then I   → My issues
G then A   → All issues  
G then P   → Projects
/          → Command menu (search everything)
C          → Create issue
T          → Change title (when issue is focused)
A          → Assign
S          → Change status
P          → Change priority
```

Linear vs Jira: Jira is more configurable and integrates with the Atlassian ecosystem. Linear is faster, has a cleaner data model, and has a better API. For teams under ~50 engineers, Linear is almost always the right choice. The Construx default: Linear for all active product development; GitHub Issues for open-source projects.
