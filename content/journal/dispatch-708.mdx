Loading an entire file into a Buffer before processing it is the wrong pattern for anything over a few MB. Streams let you start processing the first bytes while the rest are still arriving over the network or disk.

## Node.js streams: the three types

```ts
import { Readable, Writable, Transform, pipeline } from 'stream';
import { promisify }                                from 'util';
import { createReadStream, createWriteStream }      from 'fs';
import { createGzip }                               from 'zlib';

const pipelineAsync = promisify(pipeline);

// Read a large log file, gzip it, write to disk — without loading into memory
await pipelineAsync(
  createReadStream('/var/log/app.log'),     // Readable
  createGzip(),                             // Transform (built-in)
  createWriteStream('/var/log/app.log.gz'), // Writable
);
// Memory usage: ~64KB regardless of file size
```

## Custom transform stream

```ts
import { Transform } from 'stream';

// Filter log lines by severity
class LogFilter extends Transform {
  private level: string;

  constructor(level: 'ERROR' | 'WARN' | 'INFO') {
    super({ objectMode: false });
    this.level = level;
  }

  _transform(chunk: Buffer, _encoding: string, callback: () => void) {
    const line = chunk.toString();
    if (line.includes(`"level":"${this.level}"`)) {
      this.push(chunk);
    }
    callback();
  }
}

// Usage
await pipelineAsync(
  createReadStream('app.log'),
  new LogFilter('ERROR'),
  createWriteStream('errors.log'),
);
```

## Line-by-line processing with readline

```ts
import { createInterface } from 'readline';
import { createReadStream } from 'fs';

const rl = createInterface({
  input: createReadStream('large-file.csv'),
  crlfDelay: Infinity,
});

let lineCount = 0;
let errorCount = 0;

for await (const line of rl) {
  lineCount++;
  const cols = line.split(',');
  if (cols[3] === 'ERROR') errorCount++;
  // Memory: only one line at a time
}

console.log(`${errorCount} errors in ${lineCount} lines`);
```

## Web Streams API (browser + Workers)

```ts
// Works in browsers, Cloudflare Workers, Deno, Node.js 18+

// Fetch response body is a ReadableStream
const response = await fetch('https://api.example.com/large-dataset');
const reader   = response.body!.getReader();
const decoder  = new TextDecoder();

let buffer = '';
let total  = 0;

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buffer += decoder.decode(value, { stream: true });
  const lines = buffer.split('\n');
  buffer = lines.pop()!;  // keep incomplete last line
  for (const line of lines) {
    total += line.length;
  }
}
```

## TransformStream (Web Streams)

```ts
// Transform JSON stream to CSV
function jsonToCsvTransform(): TransformStream<string, string> {
  let isFirst = true;
  return new TransformStream({
    transform(chunk, controller) {
      const record = JSON.parse(chunk);
      if (isFirst) {
        controller.enqueue(Object.keys(record).join(',') + '\n');
        isFirst = false;
      }
      controller.enqueue(Object.values(record).join(',') + '\n');
    },
  });
}

// Pipe: fetch JSON → transform to CSV → Response body
const { readable, writable } = new TransformStream();
const transform = jsonToCsvTransform();
fetch('/api/export')
  .then((res) => res.body!.pipeThrough(transform).pipeTo(writable));

return new Response(readable, {
  headers: { 'Content-Type': 'text/csv', 'Content-Disposition': 'attachment; filename=export.csv' },
});
```

## Streaming HTTP responses in Next.js

```ts
// app/api/export/route.ts
export async function GET() {
  const encoder = new TextEncoder();

  const stream = new ReadableStream({
    async start(controller) {
      controller.enqueue(encoder.encode('id,title,date\n'));
      const cursor = db.posts.cursor({ where: { published: true } });
      for await (const post of cursor) {
        controller.enqueue(encoder.encode(`${post.id},"${post.title}",${post.publishedAt}\n`));
      }
      controller.close();
    },
  });

  return new Response(stream, {
    headers: { 'Content-Type': 'text/csv', 'Content-Disposition': 'attachment; filename=posts.csv' },
  });
}
```

## When to use streams

Use streams for: large file processing (CSV imports, log analysis, backups), HTTP responses where data is generated progressively (AI text, export downloads), real-time data pipelines. Do not use streams for: small data that fits comfortably in memory, simple request/response patterns where simplicity matters more than memory. The rule of thumb: if the data might be larger than 10MB, use a stream.
