Middleware sits between the user and your application. Check auth there and you protect every route without touching individual pages.

## Basic middleware

```ts
// middleware.ts (at the project root, same level as app/)
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  // Redirect old paths
  if (pathname.startsWith('/blog')) {
    return NextResponse.redirect(new URL('/journal' + pathname.slice(5), request.url));
  }

  // Add a header to every response
  const response = NextResponse.next();
  response.headers.set('X-Construx-Version', '2.0');
  return response;
}

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico).*)'],
};
```

## Auth guard

```ts
// middleware.ts
import { NextResponse }     from 'next/server';
import type { NextRequest }  from 'next/server';
import { jwtVerify }         from 'jose';

const PUBLIC_ROUTES = ['/', '/login', '/signup', '/about'];
const JWT_SECRET    = new TextEncoder().encode(process.env.JWT_SECRET);

export async function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  // Skip public routes
  if (PUBLIC_ROUTES.some((r) => pathname === r || pathname.startsWith(r + '/'))) {
    return NextResponse.next();
  }

  // Check auth cookie
  const token = request.cookies.get('session')?.value;

  if (!token) {
    const loginUrl = new URL('/login', request.url);
    loginUrl.searchParams.set('next', pathname);
    return NextResponse.redirect(loginUrl);
  }

  try {
    const { payload } = await jwtVerify(token, JWT_SECRET);

    // Pass user info to the app via headers
    const response = NextResponse.next();
    response.headers.set('X-User-Id',   String(payload.sub));
    response.headers.set('X-User-Role', String(payload.role));
    return response;
  } catch {
    // Invalid or expired token
    request.cookies.delete('session');
    return NextResponse.redirect(new URL('/login', request.url));
  }
}

export const config = {
  matcher: ['/dashboard/:path*', '/api/:path*', '/settings/:path*'],
};
```

## Reading middleware headers in Server Components

```tsx
// app/dashboard/page.tsx
import { headers } from 'next/headers';

export default async function DashboardPage() {
  const headersList = await headers();
  const userId = headersList.get('X-User-Id');
  const role   = headersList.get('X-User-Role');

  // Use userId to fetch user-specific data
  const user = await db.users.findUnique({ where: { id: userId! } });

  return <div>Welcome, {user?.name}</div>;
}
```

## A/B routing

```ts
export function middleware(request: NextRequest) {
  const bucket = request.cookies.get('ab-bucket')?.value
    ?? (Math.random() < 0.5 ? 'control' : 'variant');

  const response = NextResponse.rewrite(
    new URL(`/${bucket}${request.nextUrl.pathname}`, request.url),
  );

  // Persist the bucket for consistent experience
  if (!request.cookies.get('ab-bucket')) {
    response.cookies.set('ab-bucket', bucket, { maxAge: 60 * 60 * 24 * 30 });
  }

  return response;
}
```

## Geo-based routing

```ts
export function middleware(request: NextRequest) {
  const country = request.geo?.country ?? 'US';

  if (country === 'GB') {
    return NextResponse.rewrite(new URL('/uk' + request.nextUrl.pathname, request.url));
  }

  if (country === 'AU') {
    return NextResponse.redirect(new URL('https://au.construxgroup.io', request.url));
  }

  return NextResponse.next();
}
```

## Edge Runtime constraints

Middleware runs on the Edge Runtime, not Node.js. That means: no Node.js built-ins (no `fs`, no `crypto` module — use `globalThis.crypto`), no native modules, no large npm packages. For auth, use `jose` instead of `jsonwebtoken`. For database access, use a REST API or Cloudflare D1. Keep middleware under 1MB. The upside: runs globally, sub-1ms cold start, infinite scale.
