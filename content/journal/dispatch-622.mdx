S3 egress fees are a well-known pain. You pay to store data and again to serve it. For a site serving images or videos at scale, egress can exceed storage costs by 10x. R2 eliminates the egress fee entirely — the data is served through Cloudflare's CDN, which is already built into the network.

## R2 vs S3 pricing (2030)

| Cost           | AWS S3                   | Cloudflare R2         |
|----------------|--------------------------|----------------------|
| Storage        | $0.023/GB/month          | $0.015/GB/month      |
| Egress         | $0.09/GB                 | $0.00 (free)         |
| Class A ops    | $0.005/1,000 requests    | $4.50/million        |
| Class B ops    | $0.0004/1,000 requests   | $0.36/million        |

For a bucket serving 100TB/month of video: S3 egress = ~$9,000/month. R2 egress = $0.

## S3 SDK compatibility

R2 is S3-compatible. Replace the endpoint and credentials:

```ts
import { S3Client, PutObjectCommand, GetObjectCommand } from '@aws-sdk/client-s3';
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';

const r2 = new S3Client({
  region:   'auto',
  endpoint: `https://${process.env.CF_ACCOUNT_ID}.r2.cloudflarestorage.com`,
  credentials: {
    accessKeyId:     process.env.R2_ACCESS_KEY_ID!,
    secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
  },
});

// Upload
await r2.send(new PutObjectCommand({
  Bucket: 'construx-media',
  Key:    `uploads/${userId}/${filename}`,
  Body:   fileBuffer,
  ContentType: mimeType,
}));

// Signed URL (time-limited download link)
const url = await getSignedUrl(
  r2,
  new GetObjectCommand({ Bucket: 'construx-media', Key: objectKey }),
  { expiresIn: 3600 },  // 1 hour
);
```

Your existing AWS S3 code migrates by changing the endpoint. The SDK API is identical.

## Workers binding: zero-latency access from the edge

When using Cloudflare Workers, you can access R2 directly via a binding — no HTTP requests, no credentials:

```ts
// wrangler.toml
[[r2_buckets]]
binding = "MEDIA"
bucket_name = "construx-media"
```

```ts
// worker.ts
export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url);
    const key = url.pathname.slice(1);  // /filename.jpg → filename.jpg

    if (request.method === 'GET') {
      const object = await env.MEDIA.get(key);
      if (!object) return new Response('Not found', { status: 404 });

      return new Response(object.body, {
        headers: {
          'Content-Type':  object.httpMetadata?.contentType ?? 'application/octet-stream',
          'Cache-Control': 'public, max-age=31536000',
          'ETag':          object.etag,
        },
      });
    }

    if (request.method === 'PUT') {
      await env.MEDIA.put(key, request.body, {
        httpMetadata: { contentType: request.headers.get('Content-Type') ?? undefined },
      });
      return new Response('OK');
    }

    return new Response('Method not allowed', { status: 405 });
  },
};

interface Env {
  MEDIA: R2Bucket;
}
```

The binding is a direct call to R2's internal API — faster than an HTTP request to an external endpoint.

## Public access via custom domain

```toml
# wrangler.toml — enable R2 public access
[[r2_buckets]]
binding    = "MEDIA"
bucket_name = "construx-media"

# Or configure in the R2 dashboard: Settings → Custom Domains
# media.construxgroup.io → construx-media bucket
```

With a custom domain, objects at `media.construxgroup.io/path/to/file.jpg` are served directly from Cloudflare's CDN — no Worker needed, no egress fees, full CDN caching.

## Presigned URLs for secure uploads

Direct browser-to-R2 uploads without routing through your server:

```ts
// API route: generate a presigned upload URL
export async function POST(req: Request) {
  const { filename, contentType } = await req.json();
  const key = `uploads/${crypto.randomUUID()}/${filename}`;

  const url = await getSignedUrl(
    r2,
    new PutObjectCommand({
      Bucket:      'construx-media',
      Key:         key,
      ContentType: contentType,
    }),
    { expiresIn: 300 },  // 5 minute upload window
  );

  return Response.json({ uploadUrl: url, key });
}
```

```ts
// Client: upload directly to R2
const { uploadUrl, key } = await fetch('/api/upload-url', {
  method:  'POST',
  headers: { 'Content-Type': 'application/json' },
  body:    JSON.stringify({ filename: file.name, contentType: file.type }),
}).then((r) => r.json());

await fetch(uploadUrl, {
  method:  'PUT',
  body:    file,
  headers: { 'Content-Type': file.type },
});

// Now save `key` to your database
```

## Migration from S3

1. Create R2 bucket in Cloudflare dashboard
2. Generate R2 API credentials (API Tokens → Create Token → R2 Edit)
3. Update `endpoint` and credentials in your S3 client
4. Test with a small subset of objects
5. Copy objects: `aws s3 sync s3://old-bucket/ s3://r2-bucket/ --endpoint-url https://ACCOUNT.r2.cloudflarestorage.com`

The Cloudflare Migrator tool handles bulk migration from S3 to R2 automatically.
