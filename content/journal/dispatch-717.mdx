Cypress was first-mover in modern E2E testing. Playwright is the better option for most teams today: faster parallel execution, cross-browser by default, better network mocking, and no need for a separate server process.

## Install

```bash
npm install -D @playwright/test
npx playwright install  # download browser binaries
```

## Basic test

```ts
// tests/posts.spec.ts
import { test, expect } from '@playwright/test';

test('user can create a post', async ({ page }) => {
  await page.goto('/login');
  await page.fill('[name="email"]',    'lewis@construxgroup.io');
  await page.fill('[name="password"]', 'testpassword');
  await page.click('button[type="submit"]');

  await expect(page).toHaveURL('/dashboard');

  await page.click('text=New Post');
  await page.fill('[name="title"]',   'My Test Post');
  await page.fill('[name="content"]', 'This is the content of my test post.');
  await page.click('button:has-text("Publish")');

  await expect(page.locator('h1')).toContainText('My Test Post');
  await expect(page).toHaveURL(/\/journal\//);
});
```

## playwright.config.ts

```ts
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir:     './tests',
  fullyParallel: true,
  forbidOnly:  !!process.env.CI,
  retries:     process.env.CI ? 2 : 0,
  workers:     process.env.CI ? 1 : undefined,
  reporter:    'html',

  use: {
    baseURL:      'http://localhost:3000',
    trace:        'on-first-retry',   // record traces on failure
    screenshot:   'only-on-failure',
    video:        'on-first-retry',
  },

  projects: [
    { name: 'chromium', use: { ...devices['Desktop Chrome'] } },
    { name: 'firefox',  use: { ...devices['Desktop Firefox'] } },
    { name: 'webkit',   use: { ...devices['Desktop Safari'] } },
    { name: 'mobile',   use: { ...devices['iPhone 14'] } },
  ],

  webServer: {
    command:   'npm run build && npm run start',
    url:       'http://localhost:3000',
    reuseExistingServer: !process.env.CI,
  },
});
```

## Page Object Model

```ts
// tests/pages/PostEditorPage.ts
import type { Page } from '@playwright/test';

export class PostEditorPage {
  constructor(private page: Page) {}

  async goto()                          { await this.page.goto('/posts/new'); }
  async fillTitle(title: string)        { await this.page.fill('[name="title"]', title); }
  async fillContent(content: string)    { await this.page.fill('[name="content"]', content); }
  async publish()                       { await this.page.click('button:has-text("Publish")'); }
  async expectPublished(title: string)  { await expect(this.page.locator('h1')).toContainText(title); }
}

// tests/posts.spec.ts
test('create post', async ({ page }) => {
  const editor = new PostEditorPage(page);
  await editor.goto();
  await editor.fillTitle('My post');
  await editor.fillContent('Content here.');
  await editor.publish();
  await editor.expectPublished('My post');
});
```

## Network interception

```ts
test('handles API errors gracefully', async ({ page }) => {
  // Intercept the posts API and return an error
  await page.route('/api/posts', (route) =>
    route.fulfill({ status: 500, body: 'Internal Server Error' }),
  );

  await page.goto('/posts');
  await expect(page.locator('[data-testid="error-message"]')).toBeVisible();
  await expect(page.locator('[data-testid="retry-button"]')).toBeVisible();
});

// Mock a successful response
await page.route('/api/posts', (route) =>
  route.fulfill({
    status: 200,
    contentType: 'application/json',
    body: JSON.stringify([{ id: '1', title: 'Mocked post' }]),
  }),
);
```

## Running tests

```bash
# Run all tests
npx playwright test

# Run a specific file
npx playwright test tests/posts.spec.ts

# Run with UI mode (interactive, watch mode)
npx playwright test --ui

# Debug a specific test
npx playwright test --debug tests/posts.spec.ts

# Show trace of a failed test
npx playwright show-trace test-results/trace.zip
```

## Playwright vs Cypress vs Vitest browser mode

Playwright: cross-browser, parallel, fastest, excellent network interception, trace viewer. Cypress: strong community, time-travel debugging, less cross-browser flexibility. Vitest browser mode: component tests in a real browser, not full E2E. Use Playwright for critical user flows (checkout, auth, form submission). Use Vitest for component logic and unit tests.
