Prompt engineering tells Claude what to say. Tool use tells Claude what to do. When Claude needs to look something up, run a calculation, or trigger an action in your system, tools are the right primitive — not instructions to embed the output in its text response.

## The basic pattern

```ts
import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic();

const tools: Anthropic.Tool[] = [
  {
    name: 'get_product_price',
    description: 'Get the current price and stock status for a product by its ASIN',
    input_schema: {
      type: 'object' as const,
      properties: {
        asin: {
          type: 'string',
          description: 'The Amazon Standard Identification Number for the product',
        },
        marketplace: {
          type: 'string',
          enum: ['UK', 'US', 'DE', 'FR'],
          description: 'Which marketplace to check. Defaults to UK.',
        },
      },
      required: ['asin'],
    },
  },
];

const response = await client.messages.create({
  model: 'claude-sonnet-4-6',
  max_tokens: 1024,
  tools,
  messages: [
    { role: 'user', content: 'What\'s the price of B09X3Y4Z12 on Amazon UK?' },
  ],
});
```

## Handling the tool call loop

Claude returns a `tool_use` content block when it wants to call a tool. You execute the function, return the result, and let Claude continue:

```ts
async function runWithTools(userMessage: string): Promise<string> {
  const messages: Anthropic.MessageParam[] = [
    { role: 'user', content: userMessage },
  ];

  while (true) {
    const response = await client.messages.create({
      model: 'claude-sonnet-4-6',
      max_tokens: 2048,
      tools,
      messages,
    });

    // No tool calls — Claude is done
    if (response.stop_reason === 'end_turn') {
      const textBlock = response.content.find((b) => b.type === 'text');
      return (textBlock as Anthropic.TextBlock)?.text ?? '';
    }

    // Process tool calls
    const toolResults: Anthropic.ToolResultBlockParam[] = [];

    for (const block of response.content) {
      if (block.type !== 'tool_use') continue;

      const result = await executeTool(block.name, block.input as Record<string, unknown>);

      toolResults.push({
        type: 'tool_result',
        tool_use_id: block.id,
        content: JSON.stringify(result),
      });
    }

    // Append assistant's response and tool results, then continue
    messages.push({ role: 'assistant', content: response.content });
    messages.push({ role: 'user', content: toolResults });
  }
}
```

```ts
async function executeTool(name: string, input: Record<string, unknown>) {
  switch (name) {
    case 'get_product_price': {
      const { asin, marketplace = 'UK' } = input as { asin: string; marketplace?: string };
      return await scoutrScan(asin, marketplace);
    }
    case 'search_products': {
      const { query, limit = 10 } = input as { query: string; limit?: number };
      return await db.query.products.findMany({
        where: (p, { ilike }) => ilike(p.title, `%${query}%`),
        limit,
      });
    }
    default:
      return { error: `Unknown tool: ${name}` };
  }
}
```

## Forcing a specific tool

`tool_choice` forces Claude to always call a specific tool — useful for structured extraction where you want a guaranteed schema:

```ts
const response = await client.messages.create({
  model: 'claude-sonnet-4-6',
  max_tokens: 1024,
  tools: [extractionTool],
  tool_choice: { type: 'tool', name: 'extract_product_details' },
  messages: [
    {
      role: 'user',
      content: `Extract the product details from this listing: ${rawListingText}`,
    },
  ],
});

// Claude always calls extract_product_details — no text response possible
const toolUse = response.content[0] as Anthropic.ToolUseBlock;
const details = toolUse.input as ProductDetails;
```

## Multi-tool agentic pipeline

```ts
const agentTools: Anthropic.Tool[] = [
  {
    name: 'search_products',
    description: 'Search the Construx product database by keyword or category',
    input_schema: { type: 'object', properties: { query: { type: 'string' }, category: { type: 'string' } }, required: ['query'] },
  },
  {
    name: 'run_price_scan',
    description: 'Trigger a real-time price scan for a product across marketplaces',
    input_schema: { type: 'object', properties: { productId: { type: 'string' } }, required: ['productId'] },
  },
  {
    name: 'create_alert',
    description: 'Create a price alert for a product at a given threshold',
    input_schema: {
      type: 'object',
      properties: {
        productId: { type: 'string' },
        threshold: { type: 'number', description: 'Alert when price drops below this value in pence' },
      },
      required: ['productId', 'threshold'],
    },
  },
];

// Claude orchestrates: search → scan → create alert, in sequence or parallel
const result = await runWithTools(
  'Find LEGO Technic sets under £50 and set up price alerts when they drop below £40'
);
```

## Tool design principles

**One tool per action**. Don't bundle multiple operations into one tool — Claude will call each step independently, which gives you control at each step.

**Descriptions over schemas**. The `description` field matters more than the `input_schema` for Claude's tool selection. Be specific about when to use the tool and what it returns.

**Return structured errors**. When a tool fails, return `{ error: "description", code: "NOT_FOUND" }` rather than throwing. Claude can handle error responses and adjust its approach — exceptions break the loop.

**Validate inputs server-side**. Claude produces valid JSON for your schema, but treat tool inputs as untrusted user input. Validate before executing database queries or API calls.

## With the Vercel AI SDK

If you're using the AI SDK, tool calling integrates cleanly:

```ts
import { generateText, tool } from 'ai';
import { anthropic } from '@ai-sdk/anthropic';
import { z } from 'zod';

const { text } = await generateText({
  model: anthropic('claude-sonnet-4-6'),
  tools: {
    getPrice: tool({
      description: 'Get product price by ASIN',
      parameters: z.object({ asin: z.string(), marketplace: z.enum(['UK', 'US']).default('UK') }),
      execute: async ({ asin, marketplace }) => scoutrScan(asin, marketplace),
    }),
  },
  maxSteps: 10,
  prompt: 'What is the current price of B09X3Y4Z12?',
});
```

The SDK handles the tool call loop automatically — `maxSteps` sets the ceiling on how many rounds of tool use Claude can run before returning.
