Load testing that fits in a one-liner and shows results as they arrive.

## Install

```bash
# macOS
brew install oha

# Linux
cargo install oha

# Pre-built binary
curl -L https://github.com/hatoo/oha/releases/latest/download/oha-linux-amd64 -o oha && chmod +x oha
```

## Basic load test

```bash
# 200 concurrent connections, 10 seconds
oha -c 200 -z 10s https://construxgroup.io/api/v1/workspaces

# 10,000 total requests
oha -n 10000 https://construxgroup.io/

# With custom headers and body (POST)
oha -c 50 -n 1000 \
  -m POST \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"name":"test","slug":"test-123"}' \
  https://construxgroup.io/api/v1/workspaces
```

## Ramp up concurrency

```bash
# Start low, see where latency degrades
oha -c 10   -z 30s https://api.construxgroup.io/health &
oha -c 50   -z 30s https://api.construxgroup.io/health &
oha -c 200  -z 30s https://api.construxgroup.io/health &
oha -c 1000 -z 30s https://api.construxgroup.io/health
```

## Use in CI as a performance gate

```bash
# scripts/load-test.sh
set -euo pipefail

ENDPOINT="https://staging.construxgroup.io/api/v1/workspaces"
CONCURRENCY=100
REQUESTS=5000
P99_MAX_MS=200

echo "Running load test: $CONCURRENCY concurrent, $REQUESTS requests"

# Run and capture JSON output
RESULT=$(oha -c "$CONCURRENCY" -n "$REQUESTS" --json "$ENDPOINT")

P99=$(echo "$RESULT" | jq '.latencyPercentiles."p99" * 1000 | round')
RPS=$(echo "$RESULT" | jq '.rps | round')
ERRORS=$(echo "$RESULT" | jq '.totalRequests - .statusCodeDistribution."200"')

echo "p99: ${P99}ms (limit: ${P99_MAX_MS}ms)"
echo "Requests/sec: $RPS"
echo "Errors: $ERRORS"

if [ "$P99" -gt "$P99_MAX_MS" ]; then
  echo "FAIL: p99 ${P99}ms exceeds ${P99_MAX_MS}ms threshold"
  exit 1
fi

echo "PASS"
```

## oha vs wrk vs k6 vs autocannon

oha: real-time TUI, Rust speed, JSON output, single binary. wrk: Lua scripting, no TUI, very fast, requires C build. k6: JavaScript scripting, complex scenarios, browser testing, CI integration. autocannon: Node.js, good for Node services, HTTP/2 support. The Construx default: oha for quick one-liner tests during development; k6 for scripted load test scenarios in CI.
