Desktop and mobile apps from a web frontend and a Rust backend. No Chromium bundle, no Electron weight.

## Install

```bash
npm create tauri-app@latest construx-desktop
# Choose: TypeScript, npm, Next.js
cd construx-desktop
npm install
```

## Project structure

```
src/              # Web frontend (Next.js / React / plain HTML)
src-tauri/
  src/
    main.rs       # Tauri entry point
    lib.rs        # Commands and event handlers
  tauri.conf.json # App config, permissions, bundle settings
  Cargo.toml      # Rust dependencies
```

## Define a Tauri command (Rust → JS)

```rust
// src-tauri/src/lib.rs
use tauri::command;
use std::fs;

#[command]
fn read_config_file(path: String) -> Result<String, String> {
    fs::read_to_string(&path)
        .map_err(|e| e.to_string())
}

#[command]
async fn fetch_with_auth(url: String, token: String) -> Result<String, String> {
    let client   = reqwest::Client::new();
    let response = client
        .get(&url)
        .header("Authorization", format!("Bearer {token}"))
        .send()
        .await
        .map_err(|e| e.to_string())?;
    response.text().await.map_err(|e| e.to_string())
}

#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .invoke_handler(tauri::generate_handler![read_config_file, fetch_with_auth])
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

## Call commands from the frontend

```ts
// src/lib/tauri.ts
import { invoke } from '@tauri-apps/api/core';

export async function readConfigFile(path: string): Promise<string> {
  return invoke<string>('read_config_file', { path });
}

export async function fetchWithAuth(url: string, token: string): Promise<string> {
  return invoke<string>('fetch_with_auth', { url, token });
}
```

```tsx
// src/app/page.tsx
'use client';
import { readConfigFile } from '@/lib/tauri';
import { useState }       from 'react';

export default function HomePage() {
  const [config, setConfig] = useState('');

  return (
    <div>
      <button onClick={async () => {
        const content = await readConfigFile('/Users/lewis/.construx/config.toml');
        setConfig(content);
      }}>
        Load config
      </button>
      <pre>{config}</pre>
    </div>
  );
}
```

## System tray and native menus

```rust
// src-tauri/src/lib.rs
use tauri::{
    menu::{Menu, MenuItem},
    tray::TrayIconBuilder,
    Manager,
};

pub fn run() {
    tauri::Builder::default()
        .setup(|app| {
            let quit  = MenuItem::with_id(app, "quit",  "Quit",  true, None::<&str>)?;
            let show  = MenuItem::with_id(app, "show",  "Show",  true, None::<&str>)?;
            let menu  = Menu::with_items(app, &[&show, &quit])?;

            TrayIconBuilder::new()
                .menu(&menu)
                .on_menu_event(|app, event| {
                    if event.id == "quit" { app.exit(0); }
                    if event.id == "show" {
                        let window = app.get_webview_window("main").unwrap();
                        window.show().unwrap();
                    }
                })
                .build(app)?;
            Ok(())
        })
        .invoke_handler(tauri::generate_handler![])
        .run(tauri::generate_context!())
        .unwrap();
}
```

## Build

```bash
# Development
npm run tauri dev

# Build desktop (macOS, Windows, Linux)
npm run tauri build

# Build for iOS (requires Xcode)
npm run tauri ios build

# Build for Android (requires Android Studio)
npm run tauri android build
```

## Bundle sizes

| App          | Bundle size |
|--------------|-------------|
| Tauri 2      | 5-12 MB     |
| Electron     | 80-150 MB   |
| NW.js        | 80-120 MB   |

The size difference is from OS webview reuse. On macOS, Tauri uses WebKit; on Windows, WebView2; on Linux, WebKitGTK. No Chromium copy in the bundle.

Tauri vs Electron: Tauri is smaller, safer (Rust backend with explicit permission model), but requires Rust knowledge. Electron has a larger ecosystem and is easier for JavaScript-only teams. The Construx default: Tauri for any new desktop tool; the Rust backend has the same permission model as a browser extension, which makes the security story much cleaner.
