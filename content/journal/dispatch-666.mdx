AWS S3 storage is cheap — $0.023/GB per month. But egress is $0.09/GB. A site serving 100GB/day of images pays $270/month in egress alone, not counting storage. R2 charges for storage only. The same workload: $0.

## Setup

```bash
npm install @aws-sdk/client-s3 @aws-sdk/s3-request-presigner
```

R2 is S3-compatible — you use the AWS SDK pointed at the R2 endpoint.

```ts
// lib/r2.ts
import { S3Client } from '@aws-sdk/client-s3';

export const r2 = new S3Client({
  region:   'auto',
  endpoint: `https://${process.env.CLOUDFLARE_ACCOUNT_ID}.r2.cloudflarestorage.com`,
  credentials: {
    accessKeyId:     process.env.R2_ACCESS_KEY_ID!,
    secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
  },
});

export const BUCKET = process.env.R2_BUCKET_NAME!;
```

## Upload

```ts
import { PutObjectCommand } from '@aws-sdk/client-s3';
import { r2, BUCKET }      from '@/lib/r2';

async function uploadFile(key: string, body: Buffer, contentType: string) {
  await r2.send(
    new PutObjectCommand({
      Bucket:      BUCKET,
      Key:         key,
      Body:        body,
      ContentType: contentType,
      CacheControl: 'public, max-age=31536000, immutable',
    }),
  );
  return `https://assets.construxgroup.io/${key}`;  // via custom domain
}
```

## Presigned URLs (direct browser upload)

```ts
import { PutObjectCommand, GetObjectCommand } from '@aws-sdk/client-s3';
import { getSignedUrl }                       from '@aws-sdk/s3-request-presigner';
import { r2, BUCKET }                         from '@/lib/r2';
import { randomUUID }                         from 'crypto';

// Generate a presigned PUT URL — browser uploads directly to R2, bypassing your server
export async function getUploadUrl(contentType: string, maxBytes: number) {
  const key = `uploads/${randomUUID()}`;
  const url = await getSignedUrl(
    r2,
    new PutObjectCommand({
      Bucket:         BUCKET,
      Key:            key,
      ContentType:    contentType,
      ContentLength:  maxBytes,
    }),
    { expiresIn: 300 },  // 5 minutes
  );
  return { url, key };
}

// Generate a presigned GET URL for private objects
export async function getDownloadUrl(key: string) {
  return getSignedUrl(
    r2,
    new GetObjectCommand({ Bucket: BUCKET, Key: key }),
    { expiresIn: 3600 },  // 1 hour
  );
}
```

## API route for presigned upload

```ts
// app/api/upload/route.ts
import { NextRequest }  from 'next/server';
import { getUploadUrl } from '@/lib/r2';
import { auth }         from '@/lib/auth';

export async function POST(req: NextRequest) {
  const session = await auth();
  if (!session) return new Response('Unauthorized', { status: 401 });

  const { contentType, size } = await req.json();
  if (size > 10 * 1024 * 1024) {
    return Response.json({ error: 'File too large (max 10MB)' }, { status: 413 });
  }

  const { url, key } = await getUploadUrl(contentType, size);
  return Response.json({ url, key });
}
```

Client flow: request presigned URL from your API → PUT file directly to R2 → store the key in your database.

## Custom domain and Workers

```ts
// Serve R2 objects via a Cloudflare Worker on your custom domain
// workers/assets.ts
export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url      = new URL(request.url);
    const key      = url.pathname.slice(1);  // strip leading /
    const object   = await env.BUCKET.get(key);

    if (!object) return new Response('Not Found', { status: 404 });

    const headers = new Headers();
    object.writeHttpMetadata(headers);
    headers.set('Cache-Control', 'public, max-age=31536000, immutable');
    headers.set('ETag', object.httpEtag);

    return new Response(object.body, { headers });
  },
};
```

## List and delete

```ts
import { ListObjectsV2Command, DeleteObjectCommand } from '@aws-sdk/client-s3';
import { r2, BUCKET } from '@/lib/r2';

// List objects with a prefix
const list = await r2.send(
  new ListObjectsV2Command({ Bucket: BUCKET, Prefix: 'uploads/', MaxKeys: 100 }),
);
const keys = list.Contents?.map((obj) => obj.Key) ?? [];

// Delete a single object
await r2.send(new DeleteObjectCommand({ Bucket: BUCKET, Key: 'uploads/old-file.png' }));
```

## R2 vs S3 vs Cloudflare Images

R2: general-purpose object storage, zero egress, S3-compatible. S3: more features (Intelligent-Tiering, event notifications, Glacier), but egress fees. Cloudflare Images: image-specific service with on-the-fly resizing and format conversion — sits on top of R2, adds per-image delivery pricing but removes manual resizing work. For most file storage needs (user uploads, backups, static assets), R2 is the obvious choice when you're already in the Cloudflare ecosystem.
