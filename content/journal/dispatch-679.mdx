Most analytics platforms are data silos. You capture events, they store them, you query them. PostHog goes further: analytics, session replay, feature flags, A/B testing, and surveys are all in one tool, sharing the same event stream. A funnel drop-off links directly to session recordings of users who dropped off.

## Setup

```bash
npm install posthog-js posthog-node
```

```tsx
// app/providers.tsx
'use client';

import posthog from 'posthog-js';
import { PostHogProvider } from 'posthog-js/react';
import { useEffect } from 'react';

export function PHProvider({ children }: { children: React.ReactNode }) {
  useEffect(() => {
    posthog.init(process.env.NEXT_PUBLIC_POSTHOG_KEY!, {
      api_host:          process.env.NEXT_PUBLIC_POSTHOG_HOST ?? 'https://app.posthog.com',
      capture_pageview:  false,  // manual pageview control with Next.js App Router
      capture_pageleave: true,
      session_recording: { maskAllInputs: true },
    });
  }, []);

  return <PostHogProvider client={posthog}>{children}</PostHogProvider>;
}
```

## Capturing events (client)

```tsx
import { usePostHog } from 'posthog-js/react';

function CheckoutButton({ planId }: { planId: string }) {
  const posthog = usePostHog();

  const handleClick = () => {
    posthog.capture('checkout_started', {
      plan_id:    planId,
      source:     'pricing_page',
      experiment: 'v2_cta',
    });
    router.push(`/checkout?plan=${planId}`);
  };

  return <button onClick={handleClick}>Start trial</button>;
}
```

## Pageview tracking (App Router)

```tsx
// components/PostHogPageview.tsx
'use client';

import { usePathname, useSearchParams } from 'next/navigation';
import { usePostHog }                   from 'posthog-js/react';
import { useEffect }                    from 'react';

export function PostHogPageview() {
  const pathname     = usePathname();
  const searchParams = useSearchParams();
  const posthog      = usePostHog();

  useEffect(() => {
    posthog.capture('$pageview', { '$current_url': window.location.href });
  }, [pathname, searchParams]);

  return null;
}
```

## Server-side events (Node.js)

```ts
// lib/posthog.ts
import { PostHog } from 'posthog-node';

export const phServer = new PostHog(process.env.POSTHOG_KEY!, {
  host:           process.env.NEXT_PUBLIC_POSTHOG_HOST,
  flushAt:        20,
  flushInterval:  10_000,
});

// In API route or server action:
phServer.capture({
  distinctId: userId,
  event:      'subscription_upgraded',
  properties: {
    from_plan: 'free',
    to_plan:   'pro',
    amount:    4900,
    currency:  'gbp',
  },
});

// Identify user (merge server and client profiles)
phServer.identify({
  distinctId: userId,
  properties: { email, name, plan, created_at },
});
```

## Feature flags

```ts
// Server-side flag evaluation (accurate, uses full targeting rules)
const flagEnabled = await phServer.isFeatureEnabled('new-onboarding-flow', userId);

// Client-side (cached, instant)
import { useFeatureFlagEnabled } from 'posthog-js/react';

function OnboardingFlow() {
  const newFlow = useFeatureFlagEnabled('new-onboarding-flow');
  return newFlow ? <NewOnboarding /> : <OldOnboarding />;
}
```

## A/B testing

```ts
// Server-side variant
const variant = await phServer.getFeatureFlag('checkout-cta', userId);
// variant: 'control' | 'v2_button' | 'v2_banner'

// Track exposure automatically — PostHog links the variant to conversion events
```

PostHog automatically calculates statistical significance for A/B tests. You see conversion rates per variant, the confidence interval, and whether the result is significant — all in the same tool that runs the experiment.

## PostHog vs Mixpanel vs Amplitude vs Heap

PostHog: open-source, self-hostable, feature flags and session replay included. Mixpanel: powerful analytics, no session replay or feature flags. Amplitude: enterprise analytics with journey and retention analysis. Heap: auto-capture all interactions (no manual event tracking), retroactive analysis. For product teams who want everything in one tool and ownership of their data, PostHog is the pragmatic choice.
