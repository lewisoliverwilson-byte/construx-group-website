Language models are good at reasoning but variable in output format. Ask for JSON and you might get JSON with prose before it, JSON inside markdown fences, or JSON with trailing commas. Structured output mode makes the model's output conform to a schema — no post-processing, no retry loops, no JSON.parse inside a try/catch.

## Anthropic's tool use approach

Anthropic doesn't have a dedicated structured output mode, but tool use produces structured output reliably. Force the model to call a specific tool and parse the tool's arguments:

```ts
import Anthropic from '@anthropic-ai/sdk';
import { z } from 'zod';

const client = new Anthropic();

const ProductAnalysisSchema = z.object({
  title:       z.string(),
  price:       z.number(),
  currency:    z.string().length(3),
  condition:   z.enum(['new', 'used', 'refurbished']),
  inStock:     z.boolean(),
  description: z.string(),
  features:    z.array(z.string()),
  confidence:  z.number().min(0).max(1),
});

type ProductAnalysis = z.infer<typeof ProductAnalysisSchema>;

async function analyseProduct(html: string): Promise<ProductAnalysis> {
  const response = await client.messages.create({
    model:      'claude-opus-4-8-20251101',
    max_tokens: 1024,
    tools: [
      {
        name:        'extract_product',
        description: 'Extract structured product information from page content',
        input_schema: {
          type: 'object',
          properties: {
            title:       { type: 'string', description: 'Product title' },
            price:       { type: 'number', description: 'Numeric price value' },
            currency:    { type: 'string', description: 'ISO 4217 currency code' },
            condition:   { type: 'string', enum: ['new', 'used', 'refurbished'] },
            inStock:     { type: 'boolean' },
            description: { type: 'string', description: 'Product description' },
            features:    { type: 'array', items: { type: 'string' } },
            confidence:  { type: 'number', description: 'Confidence 0-1 in the extraction' },
          },
          required: ['title', 'price', 'currency', 'condition', 'inStock', 'description', 'features', 'confidence'],
        },
      },
    ],
    tool_choice: { type: 'tool', name: 'extract_product' },  // Force this tool
    messages: [
      {
        role:    'user',
        content: `Extract product information from this page:\n\n${html}`,
      },
    ],
  });

  const toolUse = response.content.find((c) => c.type === 'tool_use');
  if (!toolUse || toolUse.type !== 'tool_use') {
    throw new Error('No tool call in response');
  }

  // Validate against Zod schema
  return ProductAnalysisSchema.parse(toolUse.input);
}
```

`tool_choice: { type: 'tool', name: 'extract_product' }` forces the model to always call this tool — it can't respond with plain text. The `input_schema` constrains the output format.

## Vercel AI SDK: generateObject

The Vercel AI SDK's `generateObject` makes this pattern cleaner:

```ts
import { generateObject } from 'ai';
import { anthropic }      from '@ai-sdk/anthropic';
import { z }              from 'zod';

const ProductSchema = z.object({
  title:       z.string().describe('Product title exactly as shown'),
  price:       z.number().describe('Numeric price without currency symbol'),
  currency:    z.string().length(3).describe('ISO 4217 currency code'),
  condition:   z.enum(['new', 'used', 'refurbished']),
  inStock:     z.boolean(),
  description: z.string().max(500).describe('Concise product description'),
  features:    z.array(z.string()).max(10),
  confidence:  z.number().min(0).max(1),
});

async function analyseProduct(html: string) {
  const { object } = await generateObject({
    model:  anthropic('claude-opus-4-8-20251101'),
    schema: ProductSchema,
    prompt: `Extract product information from this page:\n\n${html}`,
  });

  // object is typed as z.infer<typeof ProductSchema>
  return object;
}
```

`generateObject` handles the tool use pattern internally and returns the result typed from the Zod schema. No manual parsing, no type assertions.

## Array outputs

```ts
import { generateObject } from 'ai';
import { z }              from 'zod';

const CompetitorSchema = z.object({
  name:     z.string(),
  url:      z.string().url(),
  pricing:  z.enum(['free', 'freemium', 'paid']),
  strength: z.string().describe('Primary competitive advantage in one sentence'),
});

const { object: competitors } = await generateObject({
  model:  anthropic('claude-opus-4-8-20251101'),
  output: 'array',
  schema: CompetitorSchema,
  prompt: `List the top 5 competitors to this SaaS product: ${description}`,
});

// competitors: Array<{ name: string; url: string; pricing: ...; strength: string }>
```

## Streaming structured outputs

For long-form structured content, stream the object as it's generated:

```ts
import { streamObject } from 'ai';

const { partialObjectStream } = await streamObject({
  model:  anthropic('claude-opus-4-8-20251101'),
  schema: ProductSchema,
  prompt: `Extract product information from: ${html}`,
});

for await (const partial of partialObjectStream) {
  // partial is a DeepPartial<ProductSchema> — fields appear as they're generated
  console.log('Partial:', partial.title, partial.price);
}
```

## Nested schemas

Complex schemas with nested objects work the same way:

```ts
const ScanResultSchema = z.object({
  product: z.object({
    title:     z.string(),
    brand:     z.string().optional(),
    sku:       z.string().optional(),
    price:     z.number(),
    currency:  z.string(),
  }),
  market: z.object({
    avgPrice:    z.number(),
    minPrice:    z.number(),
    maxPrice:    z.number(),
    priceRank:   z.number().int().describe('1=cheapest in market'),
    competitors: z.number().int(),
  }),
  recommendation: z.object({
    action:   z.enum(['buy', 'pass', 'monitor']),
    reason:   z.string(),
    urgency:  z.enum(['high', 'medium', 'low']),
  }),
});
```

## Error handling

```ts
import { NoObjectGeneratedError } from 'ai';

try {
  const { object } = await generateObject({
    model:  anthropic('claude-opus-4-8-20251101'),
    schema: ProductSchema,
    prompt,
  });
  return object;
} catch (err) {
  if (NoObjectGeneratedError.isInstance(err)) {
    // Model couldn't generate a valid object (e.g., page wasn't a product)
    console.warn('Could not extract product:', err.message);
    return null;
  }
  throw err;
}
```

The key insight: describe fields in `.describe()` calls — the descriptions end up in the tool schema and guide the model toward the right value. `z.string().describe('ISO 4217 currency code')` makes the model return `'USD'` rather than `'US Dollars'`.
