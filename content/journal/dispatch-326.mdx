Resend is a transactional email API built for developers. The key differentiator: React Email templates — you write your email templates as React components with full TypeScript support, and Resend handles the rendering and delivery.

## Setup

```bash
npm install resend @react-email/components
```

```ts
// lib/email.ts
import { Resend } from 'resend';

export const resend = new Resend(process.env.RESEND_API_KEY!);
```

You'll need to verify a domain in the Resend dashboard and add the required DNS records (SPF, DKIM, DMARC). Without this, emails land in spam.

## Sending from a Route Handler

```ts
// app/api/contact/route.ts
import { resend } from '@/lib/email';
import { ContactConfirmation } from '@/emails/ContactConfirmation';

export async function POST(req: Request) {
  const { name, email, message } = await req.json();

  // Send confirmation to sender
  const { error: confirmError } = await resend.emails.send({
    from: 'Construx Group <hello@construxgroup.io>',
    to: [email],
    subject: 'We received your message',
    react: ContactConfirmation({ name, message }),
  });

  if (confirmError) {
    console.error('[Email] Confirmation failed:', confirmError);
  }

  // Send notification to us
  await resend.emails.send({
    from: 'Contact Form <contact@construxgroup.io>',
    to: ['lewis.oliver.wilson@googlemail.com'],
    subject: `New contact from ${name}`,
    text: `From: ${name} <${email}>\n\n${message}`,
    replyTo: email,
  });

  return Response.json({ ok: true });
}
```

## Magic link authentication

```ts
// lib/auth/magic-link.ts
import { resend } from '@/lib/email';
import { MagicLink } from '@/emails/MagicLink';
import { createToken, hashToken } from '@/lib/tokens';
import { db } from '@/db';

export async function sendMagicLink(email: string) {
  const token = createToken(); // random 32-byte hex string
  const hashedToken = hashToken(token); // SHA-256
  const expiresAt = new Date(Date.now() + 10 * 60 * 1000); // 10 minutes

  await db.magicLinks.create({
    data: { email, token: hashedToken, expiresAt },
  });

  const url = `${process.env.NEXTAUTH_URL}/auth/verify?token=${token}&email=${encodeURIComponent(email)}`;

  await resend.emails.send({
    from: 'Auth <auth@construxgroup.io>',
    to: [email],
    subject: 'Your sign-in link',
    react: MagicLink({ url, expiresInMinutes: 10 }),
  });
}
```

## Webhooks for delivery events

```ts
// app/api/email-webhook/route.ts
export async function POST(req: Request) {
  // Verify the webhook signature
  const signature = req.headers.get('resend-signature');
  const body = await req.text();

  // Verify signature with your webhook secret
  // ... (Resend provides HMAC verification docs)

  const event = JSON.parse(body);

  switch (event.type) {
    case 'email.bounced':
      await markEmailBounced(event.data.email_id, event.data.to[0]);
      break;
    case 'email.complained':
      await unsubscribeEmail(event.data.to[0]);
      break;
    case 'email.delivered':
      await recordDelivery(event.data.email_id);
      break;
  }

  return Response.json({ ok: true });
}
```

Track bounces and spam complaints. Remove bounced addresses from future sends immediately — repeated sends to bounced addresses hurt your sender reputation and can get your account suspended.

## Domain reputation

Good deliverability requires:
1. SPF record: authorises your sending domain
2. DKIM: signs emails with your private key
3. DMARC: tells receivers what to do with failures
4. Custom "from" domain — not a free Gmail/Outlook address

Resend handles DKIM automatically when you verify a domain. SPF and DMARC are one-time DNS record additions.
