The Hyve's kanban board lets teams organise cards across columns — a classic drag-and-drop interface. Before building, we evaluated three commonly recommended libraries.

## The library evaluation

**react-beautiful-dnd** — the historical default for React DnD. 28KB gzip, no longer actively maintained, doesn't support React strict mode in its current form. Eliminated immediately.

**@dnd-kit/sortable** — the modern successor, actively maintained, well-architected. 12KB gzip for the sortable preset. The API requires wrapping everything in `DndContext` and each droppable in `SortableContext`. Doable, but generates a lot of wrapper component nesting.

**Pragmatic drag and drop** — Atlassian's latest DnD library, the one that powers Jira. Excellent architecture, zero re-renders during drag (uses CSS transforms, not React state). But it's 20KB for the minimal preset and the API is complex for simple use cases.

After benchmarking, we built our own using the HTML5 Drag and Drop API. Not because the libraries were bad, but because our kanban is intentionally simple — we don't need multi-list nested sorting, we don't need virtual lists, and we don't need keyboard accessibility for DnD (we have keyboard navigation for the board itself).

## The data model

Cards and columns are in the database:

```ts
// schema
export const kanbanColumns = pgTable('kanban_columns', {
  id: uuid('id').primaryKey().defaultRandom(),
  boardId: uuid('board_id').notNull(),
  title: text('title').notNull(),
  position: integer('position').notNull(),
  createdAt: timestamp('created_at').defaultNow(),
});

export const kanbanCards = pgTable('kanban_cards', {
  id: uuid('id').primaryKey().defaultRandom(),
  columnId: uuid('column_id').notNull(),
  title: text('title').notNull(),
  description: text('description'),
  position: integer('position').notNull(),
  assigneeId: text('assignee_id'), // Clerk user ID
  dueDate: timestamp('due_date'),
  createdAt: timestamp('created_at').defaultNow(),
});
```

`position` is a float, not an integer. When you insert a card between two existing cards, you give it a position halfway between them: `(card_a.position + card_b.position) / 2`. This avoids reindexing the whole column on every move. When positions get too close (< 0.001 apart after repeated inserts), a background job reindexes the column.

## The drag and drop implementation

The HTML5 DnD API uses `draggable`, `onDragStart`, `onDragOver`, `onDrop`, and `onDragEnd`. The state machine:

1. User starts dragging a card → `onDragStart` fires, we store the card ID in state and a `dataTransfer` payload
2. Card is dragged over a column → `onDragOver` fires (needs `e.preventDefault()` to allow drop), we update a "drop target" indicator
3. Card is dropped → `onDrop` fires, we read the card ID from `dataTransfer`, update state optimistically, fire the API call

```tsx
'use client';

import { useState, useCallback } from 'react';

function KanbanBoard({ initialColumns, initialCards }: Props) {
  const [columns, setColumns] = useState(initialColumns);
  const [cards, setCards] = useState(initialCards);
  const [draggingId, setDraggingId] = useState<string | null>(null);
  const [dropTargetColumnId, setDropTargetColumnId] = useState<string | null>(null);

  const handleDragStart = useCallback((e: React.DragEvent, cardId: string) => {
    setDraggingId(cardId);
    e.dataTransfer.setData('cardId', cardId);
    e.dataTransfer.effectAllowed = 'move';
  }, []);

  const handleDragOver = useCallback((e: React.DragEvent, columnId: string) => {
    e.preventDefault();
    e.dataTransfer.dropEffect = 'move';
    setDropTargetColumnId(columnId);
  }, []);

  const handleDragLeave = useCallback(() => {
    setDropTargetColumnId(null);
  }, []);

  const handleDrop = useCallback(async (e: React.DragEvent, targetColumnId: string) => {
    e.preventDefault();
    const cardId = e.dataTransfer.getData('cardId');
    if (!cardId) return;

    const card = cards.find((c) => c.id === cardId);
    if (!card || card.columnId === targetColumnId) return;

    // Calculate new position: after the last card in the target column
    const targetCards = cards.filter((c) => c.columnId === targetColumnId);
    const newPosition = targetCards.length > 0
      ? Math.max(...targetCards.map((c) => c.position)) + 1000
      : 1000;

    // Optimistic update
    setCards((prev) => prev.map((c) =>
      c.id === cardId ? { ...c, columnId: targetColumnId, position: newPosition } : c
    ));
    setDropTargetColumnId(null);
    setDraggingId(null);

    // Persist
    await fetch('/api/kanban/move-card', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ cardId, targetColumnId, position: newPosition }),
    });
  }, [cards]);

  const handleDragEnd = useCallback(() => {
    setDraggingId(null);
    setDropTargetColumnId(null);
  }, []);

  return (
    <div className="flex gap-4 overflow-x-auto pb-4">
      {columns.map((col) => {
        const colCards = cards
          .filter((c) => c.columnId === col.id)
          .sort((a, b) => a.position - b.position);

        return (
          <div
            key={col.id}
            className="flex-shrink-0 w-64"
            onDragOver={(e) => handleDragOver(e, col.id)}
            onDragLeave={handleDragLeave}
            onDrop={(e) => handleDrop(e, col.id)}
            style={{
              border: dropTargetColumnId === col.id
                ? '1px solid rgba(249,115,22,0.4)'
                : '1px solid rgba(255,255,255,0.06)',
              borderRadius: '3px',
              transition: 'border-color 150ms',
            }}
          >
            <div className="p-3 border-b border-white/5">
              <h3 className="font-mono text-xs font-semibold">{col.title}</h3>
              <span className="font-mono text-[10px] text-text-dim">{colCards.length}</span>
            </div>
            <div className="p-2 space-y-2">
              {colCards.map((card) => (
                <div
                  key={card.id}
                  draggable
                  onDragStart={(e) => handleDragStart(e, card.id)}
                  onDragEnd={handleDragEnd}
                  style={{
                    opacity: draggingId === card.id ? 0.4 : 1,
                    cursor: 'grab',
                  }}
                  className="p-3 bg-subtle rounded border border-white/5"
                >
                  <p className="text-sm text-text-base">{card.title}</p>
                </div>
              ))}
            </div>
          </div>
        );
      })}
    </div>
  );
}
```

## The drag image

The default drag image is a screenshot of the dragged element. On dark backgrounds this looks fine, but on light backgrounds it can be jarring. We replace it with a clean floating card:

```tsx
const handleDragStart = useCallback((e: React.DragEvent, cardId: string) => {
  // Create a clone for the drag image
  const ghost = (e.currentTarget as HTMLElement).cloneNode(true) as HTMLElement;
  ghost.style.position = 'absolute';
  ghost.style.top = '-1000px';
  ghost.style.opacity = '0.9';
  document.body.appendChild(ghost);
  e.dataTransfer.setDragImage(ghost, 20, 20);
  // Clean up ghost after drag
  requestAnimationFrame(() => document.body.removeChild(ghost));

  setDraggingId(cardId);
  e.dataTransfer.setData('cardId', cardId);
}, []);
```

`setDragImage` replaces the browser's default drag preview. The `requestAnimationFrame` cleanup happens after the browser has captured the image — if you remove the element synchronously, the image capture fails.

## The performance trade-off

The HTML5 DnD API doesn't support frame-by-frame position tracking during drag. The `onDragOver` event fires periodically, not on every animation frame. This means you can't implement smooth card insertion previews (the "ghost placeholder" that shows where the card will land).

We made a deliberate trade-off: no mid-drag preview. The drop target column highlights when the card enters it. When the card drops, it appears at the end of the column. This is simpler to implement and feels adequate for the board's complexity — most drags are moving a card to a different column, not precisely ordering within a column.

If we needed within-column reordering with preview, we'd use `@dnd-kit/sortable`. For cross-column drops, the HTML5 API is sufficient.

## Persistence and optimistic updates

Every card move fires a `POST /api/kanban/move-card`. The state updates immediately (optimistic) and reverts if the API call fails:

```ts
const prevCards = cards;
setCards(/* optimistic update */);

try {
  await fetch('/api/kanban/move-card', { ... });
} catch {
  // Revert
  setCards(prevCards);
  // Show error toast
}
```

This gives immediate visual feedback while the API call happens in the background. The revert only triggers on actual failures — in practice, API calls to Amplify-hosted Next.js routes rarely fail.
