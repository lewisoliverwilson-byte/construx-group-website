Most analytics tools are black boxes: data goes in, you see charts, you have no idea what's actually being stored or whether the data leaves your infrastructure. PostHog is different — open-source, self-hostable, and ships with feature flags, session recording, and A/B testing so you're not adding a separate tool for each.

## Setup in Next.js

```bash
npm install posthog-js posthog-node
```

```tsx
// app/providers.tsx
'use client';

import posthog from 'posthog-js';
import { PostHogProvider } from 'posthog-js/react';
import { useEffect } from 'react';

export function PHProvider({ children }: { children: React.ReactNode }) {
  useEffect(() => {
    posthog.init(process.env.NEXT_PUBLIC_POSTHOG_KEY!, {
      api_host: process.env.NEXT_PUBLIC_POSTHOG_HOST ?? 'https://eu.posthog.com',
      person_profiles: 'identified_only',  // Don't create profiles for anonymous users
      capture_pageview: false,              // Handle pageviews manually for SPA
      capture_pageleave: true,
    });
  }, []);

  return <PostHogProvider client={posthog}>{children}</PostHogProvider>;
}
```

## Pageview tracking with App Router

```tsx
// components/PostHogPageView.tsx
'use client';

import { usePathname, useSearchParams } from 'next/navigation';
import { usePostHog } from 'posthog-js/react';
import { useEffect } from 'react';

export function PostHogPageView() {
  const pathname = usePathname();
  const searchParams = useSearchParams();
  const posthog = usePostHog();

  useEffect(() => {
    if (pathname && posthog) {
      let url = window.origin + pathname;
      if (searchParams.toString()) url += `?${searchParams.toString()}`;
      posthog.capture('$pageview', { $current_url: url });
    }
  }, [pathname, searchParams, posthog]);

  return null;
}
```

```tsx
// app/layout.tsx
import { Suspense } from 'react';
import { PHProvider } from './providers';
import { PostHogPageView } from '@/components/PostHogPageView';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <PHProvider>
          <Suspense>
            <PostHogPageView />
          </Suspense>
          {children}
        </PHProvider>
      </body>
    </html>
  );
}
```

## Tracking custom events

```tsx
'use client';

import { usePostHog } from 'posthog-js/react';

export function ScanButton({ productId }: { productId: string }) {
  const posthog = usePostHog();

  const handleClick = () => {
    posthog.capture('scan_initiated', {
      product_id: productId,
      source: 'product_page',
      scan_type: 'manual',
    });

    // Do the scan...
  };

  return <button onClick={handleClick}>Scan now</button>;
}
```

## Identifying users

```tsx
// Identify on login
posthog.identify(user.id, {
  email: user.email,
  name: user.name,
  plan: user.plan,
  created_at: user.createdAt.toISOString(),
  venture: 'scoutr',
});

// Reset on logout
posthog.reset();
```

## Feature flags

```tsx
'use client';

import { useFeatureFlagEnabled } from 'posthog-js/react';

export function ProductCard({ product }: { product: Product }) {
  const showPriceHistory = useFeatureFlagEnabled('price-history-chart');
  const newLayoutEnabled = useFeatureFlagEnabled('product-card-v2');

  if (newLayoutEnabled) {
    return <ProductCardV2 product={product} />;
  }

  return (
    <div className="product-card">
      <h3>{product.title}</h3>
      <span>£{product.price}</span>
      {showPriceHistory && <PriceHistoryChart productId={product.id} />}
    </div>
  );
}
```

## Server-side feature flags (for SSR)

```ts
// lib/posthog-server.ts
import { PostHog } from 'posthog-node';

export const serverPostHog = new PostHog(process.env.POSTHOG_KEY!, {
  host: process.env.POSTHOG_HOST ?? 'https://eu.posthog.com',
});
```

```tsx
// app/dashboard/page.tsx (Server Component)
import { serverPostHog } from '@/lib/posthog-server';
import { getSession } from '@/lib/auth';

export default async function DashboardPage() {
  const session = await getSession();

  const useNewDashboard = await serverPostHog.isFeatureEnabled(
    'new-dashboard-layout',
    session?.userId ?? 'anonymous'
  );

  if (useNewDashboard) return <NewDashboard />;
  return <LegacyDashboard />;
}
```

## A/B testing

```ts
// Assign variant on server, pass to client
const variant = await serverPostHog.getFeatureFlag(
  'pricing-page-test',
  userId
);

// 'control' or 'treatment'
```

```tsx
// Track conversion
posthog.capture('pricing_page_cta_clicked', {
  $feature_flag: 'pricing-page-test',
  variant,  // Which variant converted
  plan_selected: 'pro',
});
```

## Funnels

PostHog's funnel analysis looks at conversion between events in sequence:

```
1. page_viewed ($current_url = /pricing)
2. pricing_cta_clicked
3. signup_completed
4. payment_completed
```

Set these up in the PostHog dashboard — no additional tracking code required since you're already capturing all the events. PostHog correlates them automatically.

## Privacy

PostHog's default config sends data to their cloud. To keep data in your own infrastructure:

```bash
docker compose -f posthog/docker-compose.yml up -d
```

The self-hosted version is free and includes all features. It requires a server with 4GB RAM minimum. For most SaaS products, the PostHog Cloud EU region is sufficient — data stays in the EU.
