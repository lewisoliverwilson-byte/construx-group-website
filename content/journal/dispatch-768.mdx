Drizzle's `db.query` API fetches relations in one query. No N+1, no raw JOINs, no Prisma binary.

## Define relations

```ts
// src/lib/schema.ts
import { pgTable, text, timestamp, uuid } from 'drizzle-orm/pg-core';
import { relations }                       from 'drizzle-orm';

export const users = pgTable('users', {
  id:        uuid('id').primaryKey().defaultRandom(),
  email:     text('email').notNull().unique(),
  name:      text('name'),
  createdAt: timestamp('created_at').notNull().defaultNow(),
});

export const workspaces = pgTable('workspaces', {
  id:        uuid('id').primaryKey().defaultRandom(),
  ownerId:   uuid('owner_id').notNull().references(() => users.id),
  name:      text('name').notNull(),
  slug:      text('slug').notNull().unique(),
  createdAt: timestamp('created_at').notNull().defaultNow(),
});

export const posts = pgTable('posts', {
  id:          uuid('id').primaryKey().defaultRandom(),
  workspaceId: uuid('workspace_id').notNull().references(() => workspaces.id),
  authorId:    uuid('author_id').notNull().references(() => users.id),
  title:       text('title').notNull(),
  body:        text('body').notNull(),
  publishedAt: timestamp('published_at'),
  createdAt:   timestamp('created_at').notNull().defaultNow(),
});

// Define relations for db.query API
export const usersRelations = relations(users, ({ many }) => ({
  workspaces: many(workspaces),
  posts:      many(posts),
}));

export const workspacesRelations = relations(workspaces, ({ one, many }) => ({
  owner: one(users, { fields: [workspaces.ownerId], references: [users.id] }),
  posts: many(posts),
}));

export const postsRelations = relations(posts, ({ one }) => ({
  workspace: one(workspaces, { fields: [posts.workspaceId], references: [workspaces.id] }),
  author:    one(users,      { fields: [posts.authorId],    references: [users.id] }),
}));
```

## db.query — relational API

```ts
// src/lib/db.ts
import { drizzle } from 'drizzle-orm/neon-http';
import { neon }    from '@neondatabase/serverless';
import * as schema from './schema';

const sql = neon(process.env.DATABASE_URL!);
export const db = drizzle(sql, { schema });
```

```ts
// Fetch a user with their workspaces and each workspace's posts
const user = await db.query.users.findFirst({
  where: (users, { eq }) => eq(users.id, userId),
  with: {
    workspaces: {
      with: {
        posts: {
          where: (posts, { isNotNull }) => isNotNull(posts.publishedAt),
          orderBy: (posts, { desc }) => [desc(posts.publishedAt)],
          limit: 5,
        },
      },
    },
  },
});

// Type: {
//   id: string; email: string; name: string | null;
//   workspaces: Array<{
//     id: string; name: string;
//     posts: Array<{ id: string; title: string; publishedAt: Date; }>
//   }>
// }
```

Drizzle generates a single SQL query with JOINs — no N+1 queries, no waterfall round trips.

## Filters inside relations

```ts
const activeWorkspaces = await db.query.workspaces.findMany({
  where: (ws, { eq }) => eq(ws.ownerId, userId),
  with: {
    posts: {
      // Only include published posts
      where: (p, { isNotNull }) => isNotNull(p.publishedAt),
      // Columns selection — only fetch what you need
      columns: {
        id:          true,
        title:       true,
        publishedAt: true,
        // body: false — large column excluded
      },
    },
    // Include owner details
    owner: {
      columns: { email: true, name: true },
    },
  },
  orderBy: (ws, { desc }) => [desc(ws.createdAt)],
  limit: 20,
});
```

## Core SQL API — when you need full control

```ts
// db.query covers most cases
// For aggregations, window functions, or complex CTEs, use the core API
import { eq, count, avg, sql } from 'drizzle-orm';

const stats = await db
  .select({
    workspaceId: posts.workspaceId,
    postCount:   count(),
    avgLength:   avg(sql`length(${posts.body})`),
  })
  .from(posts)
  .where(isNotNull(posts.publishedAt))
  .groupBy(posts.workspaceId)
  .orderBy(desc(count()))
  .limit(10);
```

## Type inference from schema

```ts
import { InferSelectModel, InferInsertModel } from 'drizzle-orm';

type User        = InferSelectModel<typeof users>;
type NewUser     = InferInsertModel<typeof users>;
type Workspace   = InferSelectModel<typeof workspaces>;
type NewWorkspace = InferInsertModel<typeof workspaces>;
```

Drizzle vs Prisma: Drizzle uses TypeScript schema (no .prisma file), generates inspectable SQL, no binary dependency, slightly lower abstraction. Prisma has better introspection tools, more mature ecosystem, and a Prisma Client generator. The Construx default: Drizzle for new projects; the SQL transparency makes debugging significantly easier.
