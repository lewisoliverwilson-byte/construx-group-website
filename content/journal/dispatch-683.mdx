Auth is one of the most commonly reinvented wheels in web development. JWT handling, session management, OAuth dance, email verification, password reset flows, MFA — every team builds a version of this. Clerk takes it out of your codebase entirely.

## Setup

```bash
npm install @clerk/nextjs
```

```ts
// middleware.ts
import { clerkMiddleware, createRouteMatcher } from '@clerk/nextjs/server';

const isPublic = createRouteMatcher([
  '/',
  '/sign-in(.*)',
  '/sign-up(.*)',
  '/api/webhook(.*)',
  '/journal(.*)',
]);

export default clerkMiddleware((auth, req) => {
  if (!isPublic(req)) auth().protect();
});

export const config = { matcher: ['/((?!_next|.*\\..*).*)'] };
```

## Reading auth in Server Components

```tsx
// app/dashboard/page.tsx
import { auth, currentUser } from '@clerk/nextjs/server';
import { redirect }          from 'next/navigation';

export default async function DashboardPage() {
  const { userId } = auth();
  if (!userId) redirect('/sign-in');

  const user = await currentUser();

  return (
    <div>
      <h1>Welcome, {user?.firstName}</h1>
      <p>Plan: {user?.publicMetadata?.plan ?? 'free'}</p>
    </div>
  );
}
```

## Reading auth in API routes

```ts
// app/api/posts/route.ts
import { auth } from '@clerk/nextjs/server';

export async function POST(req: Request) {
  const { userId } = auth();
  if (!userId) return new Response('Unauthorized', { status: 401 });

  const body = await req.json();
  const post = await db.posts.create({ data: { ...body, authorId: userId } });
  return Response.json(post, { status: 201 });
}
```

## Webhooks: sync Clerk users to your database

```ts
// app/api/webhook/clerk/route.ts
import { Webhook }   from 'svix';
import { WebhookEvent } from '@clerk/nextjs/server';
import { headers }   from 'next/headers';

export async function POST(req: Request) {
  const wh      = new Webhook(process.env.CLERK_WEBHOOK_SECRET!);
  const payload = await req.text();
  const hdrs    = {
    'svix-id':        headers().get('svix-id')!,
    'svix-timestamp': headers().get('svix-timestamp')!,
    'svix-signature': headers().get('svix-signature')!,
  };

  const event = wh.verify(payload, hdrs) as WebhookEvent;

  if (event.type === 'user.created') {
    await db.users.create({
      data: {
        clerkId: event.data.id,
        email:   event.data.email_addresses[0]?.email_address,
        name:    `${event.data.first_name} ${event.data.last_name}`.trim(),
        plan:    'free',
      },
    });
  }

  if (event.type === 'user.deleted') {
    await db.users.delete({ where: { clerkId: event.data.id } });
  }

  return new Response('OK');
}
```

## Clerk vs NextAuth vs Lucia

Clerk: fully managed, pre-built UI, organisations, device sessions — you pay per MAU but own zero auth infrastructure. NextAuth (Auth.js): open-source, you host it, supports dozens of providers, no UI — you build the pages. Lucia: lightweight, open-source, session-based, TypeScript-first — maximum control, more code. Use Clerk when shipping speed matters more than owning the auth layer. Use Lucia or NextAuth when you need full control or want to avoid per-MAU pricing at scale.
