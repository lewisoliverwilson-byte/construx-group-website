Streaming is the difference between a spinner for three seconds and text appearing immediately. Users perceive streaming responses as faster even when total time is the same — visible progress beats invisible wait. For AI-heavy products, streaming is table stakes.

## How it works at the HTTP level

The server sends a `Transfer-Encoding: chunked` response and writes chunks as they arrive from the model. The client reads the stream with a `ReadableStream` or `EventSource`. The connection stays open until the model finishes.

```
HTTP/1.1 200 OK
Content-Type: text/plain; charset=utf-8
Transfer-Encoding: chunked

5\r\n
Hello\r\n
6\r\n
 world\r\n
0\r\n
\r\n
```

In practice, LLM APIs stream newline-delimited JSON or SSE (Server-Sent Events).

## Raw Next.js route

Without a library, a streaming API route looks like this:

```ts
// app/api/chat/route.ts
import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic();

export async function POST(req: Request) {
  const { messages } = await req.json();

  const stream = client.messages.stream({
    model:      'claude-opus-4-8-20251101',
    max_tokens: 1024,
    messages,
  });

  const readable = new ReadableStream({
    async start(controller) {
      for await (const chunk of stream) {
        if (
          chunk.type === 'content_block_delta' &&
          chunk.delta.type === 'text_delta'
        ) {
          controller.enqueue(
            new TextEncoder().encode(chunk.delta.text)
          );
        }
      }
      controller.close();
    },
    cancel() {
      stream.controller.abort();
    },
  });

  return new Response(readable, {
    headers: {
      'Content-Type':  'text/plain; charset=utf-8',
      'X-Content-Type-Options': 'nosniff',
    },
  });
}
```

Client-side consumption:

```ts
async function streamCompletion(messages: Message[]) {
  const response = await fetch('/api/chat', {
    method:  'POST',
    headers: { 'Content-Type': 'application/json' },
    body:    JSON.stringify({ messages }),
  });

  if (!response.body) throw new Error('No response body');

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let result = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    result += decoder.decode(value, { stream: true });
    setContent(result);  // Update React state on each chunk
  }
}
```

## With the Vercel AI SDK

The SDK wraps this pattern into `streamText` and `useChat`:

```ts
// app/api/chat/route.ts
import { streamText } from 'ai';
import { anthropic } from '@ai-sdk/anthropic';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model:    anthropic('claude-opus-4-8-20251101'),
    messages,
    system:   'You are a helpful assistant.',
  });

  return result.toDataStreamResponse();
}
```

```tsx
// components/Chat.tsx
'use client';

import { useChat } from 'ai/react';

export function Chat() {
  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
    api: '/api/chat',
  });

  return (
    <div>
      <div>
        {messages.map((m) => (
          <div key={m.id}>
            <strong>{m.role}:</strong> {m.content}
          </div>
        ))}
        {isLoading && <div>▋</div>}
      </div>
      <form onSubmit={handleSubmit}>
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="Type a message..."
        />
        <button type="submit" disabled={isLoading}>Send</button>
      </form>
    </div>
  );
}
```

`useChat` manages the message list, optimistically appends user messages, streams the assistant response into the last message, and handles errors. The cursor (`▋`) during `isLoading` signals to the user that content is incoming.

## Streaming with tool calls

When the model calls tools, streaming becomes more nuanced — you need to render partial tool calls and results:

```ts
// app/api/agent/route.ts
import { streamText, tool } from 'ai';
import { anthropic } from '@ai-sdk/anthropic';
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: anthropic('claude-opus-4-8-20251101'),
    messages,
    tools: {
      getWeather: tool({
        description: 'Get current weather for a location',
        parameters:  z.object({ location: z.string() }),
        execute:     async ({ location }) => {
          const data = await fetchWeather(location);
          return data;
        },
      }),
    },
    maxSteps: 5,  // Allow multiple tool call rounds
  });

  return result.toDataStreamResponse();
}
```

```tsx
// Client — useChat handles tool call state automatically
const { messages } = useChat({ api: '/api/agent' });

// messages[n].toolInvocations contains tool calls and results
{messages.map((m) => (
  <div key={m.id}>
    {m.content}
    {m.toolInvocations?.map((t) => (
      <div key={t.toolCallId}>
        <span>Tool: {t.toolName}</span>
        {t.state === 'result' && <pre>{JSON.stringify(t.result, null, 2)}</pre>}
      </div>
    ))}
  </div>
))}
```

## Abort handling

Users cancel generations. Handle it:

```tsx
const { messages, stop, isLoading } = useChat({ api: '/api/chat' });

// In the UI
{isLoading && (
  <button onClick={stop} type="button">
    Stop generating
  </button>
)}
```

On the server, the SDK propagates the abort signal to the model API call — Anthropic's SDK will cancel the in-flight request. For raw `ReadableStream` implementations, wire the abort signal manually:

```ts
const ac = new AbortController();

const stream = client.messages.stream(
  { model: '...', messages, max_tokens: 1024 },
  { signal: ac.signal }
);

const readable = new ReadableStream({
  // ...
  cancel() { ac.abort(); },
});
```

## SSE vs plain streaming

For simple text output, `text/plain` chunked responses work. For structured updates (tool calls, metadata, error events), use `text/event-stream` (SSE):

```ts
// SSE format
data: {"type":"text","text":"Hello"}\n\n
data: {"type":"tool_call","name":"search","input":{"q":"weather"}}\n\n
data: [DONE]\n\n
```

The Vercel AI SDK uses its own data stream format (`text/x-ai-data-stream`) which the client hooks parse automatically. If you're building a custom client or using a different language on the frontend, plain SSE is simpler to parse.
