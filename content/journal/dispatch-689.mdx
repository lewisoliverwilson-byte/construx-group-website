REST APIs require you to keep your server and client types in sync manually — or generate them from OpenAPI schemas. GraphQL does the same with a schema file. tRPC skips all of this: the router is the type, and TypeScript propagates it to the client automatically.

## Setup

```bash
npm install @trpc/server @trpc/client @trpc/react-query @tanstack/react-query zod
```

## Server: define procedures

```ts
// server/trpc.ts
import { initTRPC, TRPCError } from '@trpc/server';
import { z }                   from 'zod';
import superjson               from 'superjson';

interface Context {
  userId?: string;
}

const t = initTRPC.context<Context>().create({
  transformer: superjson,  // handles Date, Map, Set across the wire
});

export const router     = t.router;
export const publicProc = t.procedure;
export const authedProc = t.procedure.use(({ ctx, next }) => {
  if (!ctx.userId) throw new TRPCError({ code: 'UNAUTHORIZED' });
  return next({ ctx: { ...ctx, userId: ctx.userId } });
});
```

```ts
// server/routers/posts.ts
import { router, authedProc, publicProc } from '../trpc';
import { z } from 'zod';

export const postsRouter = router({
  list: publicProc
    .input(z.object({ limit: z.number().min(1).max(50).default(20) }))
    .query(async ({ input }) => {
      return db.posts.findMany({ take: input.limit, where: { published: true } });
    }),

  byId: publicProc
    .input(z.object({ id: z.string().uuid() }))
    .query(async ({ input }) => {
      const post = await db.posts.findUnique({ where: { id: input.id } });
      if (!post) throw new TRPCError({ code: 'NOT_FOUND' });
      return post;
    }),

  create: authedProc
    .input(z.object({ title: z.string().min(1), content: z.string().min(10) }))
    .mutation(async ({ input, ctx }) => {
      return db.posts.create({ data: { ...input, authorId: ctx.userId } });
    }),

  delete: authedProc
    .input(z.object({ id: z.string().uuid() }))
    .mutation(async ({ input, ctx }) => {
      const post = await db.posts.findUnique({ where: { id: input.id } });
      if (post?.authorId !== ctx.userId) throw new TRPCError({ code: 'FORBIDDEN' });
      return db.posts.delete({ where: { id: input.id } });
    }),
});
```

// server/routers/index.ts
import { router } from '../trpc';

## Next.js App Router integration

```ts
// app/api/trpc/[trpc]/route.ts
import { fetchRequestHandler }  from '@trpc/server/adapters/fetch';
import { appRouter }            from '@/server/routers';
import { auth }                 from '@/lib/auth';

const handler = (req: Request) =>
  fetchRequestHandler({
    endpoint:   '/api/trpc',
    req,
    router:     appRouter,
    createContext: async () => {
      const session = await auth();
      return { userId: session?.user?.id };
    },
  });

export { handler as GET, handler as POST };
```

## Client: use from React

```tsx
// lib/trpc.ts
import { createTRPCReact }     from '@trpc/react-query';
import { httpBatchLink }       from '@trpc/client';
import superjson                from 'superjson';
import type { AppRouter }      from '@/server/routers';

export const trpc = createTRPCReact<AppRouter>();

export function TRPCProvider({ children }: { children: React.ReactNode }) {
  const [client] = useState(() =>
    trpc.createClient({
      links:       [httpBatchLink({ url: '/api/trpc', transformer: superjson })],
    }),
  );
  return <trpc.Provider client={client} queryClient={queryClient}>{children}</trpc.Provider>;
}
```

```tsx
// components/PostList.tsx
'use client';
import { trpc } from '@/lib/trpc';

function PostList() {
  // Fully typed — posts is Post[], TypeScript knows the exact shape
  const posts = trpc.posts.list.useQuery({ limit: 10 });
  const create = trpc.posts.create.useMutation({
    onSuccess: () => posts.refetch(),
  });

  if (posts.isLoading) return <Skeleton />;

  return (
    <div>
      {posts.data?.map((post) => (
        <div key={post.id}>{post.title}</div>
      ))}
      <button onClick={() => create.mutate({ title: 'New Post', content: 'Content here…' })}>
        Add
      </button>
    </div>
  );
}
```

## Server-side calls (no HTTP)

```tsx
// app/posts/page.tsx — Server Component, calls the router directly
import { createCaller } from '@trpc/server';
import { appRouter }    from '@/server/routers';

export default async function PostsPage() {
  const caller = createCaller(appRouter)({ userId: undefined });
  const posts  = await caller.posts.list({ limit: 20 });
  return <ul>{posts.map((p) => <li key={p.id}>{p.title}</li>)}</ul>;
}
```

## tRPC vs GraphQL vs REST

tRPC: TypeScript monorepos only, no schema file, instant type propagation. No good story for external consumers (public APIs, mobile). GraphQL: works across languages, excellent for public APIs, complex queries and subscriptions. REST: universal, tools everywhere, best for public APIs and third-party integrations. Use tRPC when your server and client are both TypeScript in the same repo. Use GraphQL or REST for public APIs or when you need cross-language clients.
