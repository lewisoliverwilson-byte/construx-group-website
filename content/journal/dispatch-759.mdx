The cloud pricing problem has a straightforward answer: run the platform yourself.

## Install on a fresh VPS

```bash
# On Ubuntu 22.04+ or Debian 12+
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```

The installer sets up Docker, Docker Compose, and the Coolify control plane. Access the dashboard at `http://your-server-ip:8000` and complete the setup wizard.

## Add a server

```bash
# Coolify uses SSH to control remote servers
# Add your server's SSH key to the target machine

ssh-copy-id -i ~/.ssh/coolify.pub user@your-server.com
```

In the Coolify dashboard: Servers → Add Server → enter IP and SSH key. Coolify installs the Docker daemon and agent on the remote server.

## Deploy a Next.js app from GitHub

1. Connect GitHub → authorize the Coolify GitHub App
2. New Resource → Application → GitHub → select repo and branch
3. Build Pack: Nixpacks (auto-detects Next.js) or Docker
4. Set environment variables in the UI
5. Custom domain: enter your domain, Coolify provisions Let's Encrypt SSL automatically
6. Deploy

Subsequent pushes to the configured branch trigger automatic deploys via webhook.

## Nixpacks build config

Coolify uses Nixpacks to detect the framework and generate a build plan:

```toml
# nixpacks.toml — override defaults
[phases.setup]
nixPkgs = ["nodejs-18_x", "python3"]

[phases.build]
cmds = ["npm ci", "npm run build"]

[start]
cmd = "npm start"
```

## Database provisioning

In the dashboard: Resources → New Database → select Postgres, MySQL, Redis, MongoDB, or Clickhouse. Coolify spins up a container with persistent storage and provides a connection string. No external service required.

## Docker Compose services

```yaml
# docker-compose.yml — deploy as a Compose stack
services:
  app:
    build: .
    environment:
      DATABASE_URL: ${DATABASE_URL}
    labels:
      - 'coolify.managed=true'
      - 'traefik.http.routers.app.rule=Host(`app.construxgroup.io`)'

  worker:
    build: .
    command: node worker.js
    environment:
      DATABASE_URL: ${DATABASE_URL}
```

Import to Coolify as a Docker Compose resource. Coolify manages Traefik routing and SSL for labeled services.

## Cost comparison at scale

| Platform     | 3 Next.js apps + DB | Monthly |
|--------------|---------------------|---------|
| Vercel Pro   | 3x Pro seats        | ~$60    |
| Railway      | ~15 GB-RAM-hours/d  | ~$45    |
| Coolify      | Hetzner CX31 (4vCPU, 8GB) | €9 |

The Coolify approach trades some operational simplicity for a 5-8x cost reduction. For solo founders and small teams shipping stable products, it's the right trade.

## Coolify vs Dokku vs CapRover

Coolify: modern UI, Nixpacks support, multi-server, active development. Dokku: minimal, Heroku-compatible, CLI-only, excellent for simple apps. CapRover: older, Docker-based, one-click apps, less active. The Construx default: Vercel for early-stage projects (zero ops overhead), Coolify when monthly costs exceed $30.
