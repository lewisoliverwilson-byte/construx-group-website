The Claude API follows the Anthropic Messages API. You send a list of messages, Claude responds. The interesting parts are tool use (structured outputs that can call your code) and streaming (tokens arriving as they're generated, not in a single response).

## Setup

```bash
npm install @anthropic-ai/sdk
```

```ts
// lib/claude.ts
import Anthropic from '@anthropic-ai/sdk';

export const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY!,
});
```

## Basic completion

```ts
// app/api/generate/route.ts
import { anthropic } from '@/lib/claude';

export async function POST(req: Request) {
  const { prompt } = await req.json();

  const message = await anthropic.messages.create({
    model: 'claude-opus-4-8',
    max_tokens: 1024,
    messages: [{ role: 'user', content: prompt }],
  });

  const text = message.content
    .filter((b) => b.type === 'text')
    .map((b) => b.text)
    .join('');

  return Response.json({ text });
}
```

## Streaming responses

Streaming delivers tokens as Claude generates them. For long responses, this makes the UI feel instant rather than waiting 5-10s for a full response:

```ts
// app/api/stream/route.ts
export async function POST(req: Request) {
  const { prompt } = await req.json();

  const stream = anthropic.messages.stream({
    model: 'claude-opus-4-8',
    max_tokens: 2048,
    messages: [{ role: 'user', content: prompt }],
  });

  // Return a ReadableStream that forwards tokens to the browser
  const readable = new ReadableStream({
    async start(controller) {
      const encoder = new TextEncoder();

      stream.on('text', (text) => {
        controller.enqueue(encoder.encode(`data: ${JSON.stringify({ text })}\n\n`));
      });

      stream.on('finalMessage', () => {
        controller.enqueue(encoder.encode('data: [DONE]\n\n'));
        controller.close();
      });

      stream.on('error', (err) => {
        controller.error(err);
      });
    },
  });

  return new Response(readable, {
    headers: {
      'Content-Type': 'text/event-stream',
      'Cache-Control': 'no-cache',
      'Connection': 'keep-alive',
    },
  });
}
```

```tsx
// Client — read the SSE stream
async function streamGenerate(prompt: string, onToken: (text: string) => void) {
  const res = await fetch('/api/stream', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ prompt }),
  });

  const reader = res.body!.getReader();
  const decoder = new TextDecoder();

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value);
    const lines = chunk.split('\n').filter((l) => l.startsWith('data: '));
    for (const line of lines) {
      const data = line.slice(6);
      if (data === '[DONE]') return;
      const { text } = JSON.parse(data);
      onToken(text);
    }
  }
}
```

## Tool use — structured function calling

Tool use lets Claude call your defined functions. Claude decides when to use a tool, generates structured arguments, you execute the function, then return the result:

```ts
const tools: Anthropic.Tool[] = [
  {
    name: 'search_products',
    description: 'Search the product catalogue by keyword. Returns matching products with prices and availability.',
    input_schema: {
      type: 'object' as const,
      properties: {
        query: { type: 'string', description: 'Search query' },
        limit: { type: 'number', description: 'Max results to return', default: 5 },
      },
      required: ['query'],
    },
  },
  {
    name: 'get_product_details',
    description: 'Get full details for a specific product by ID.',
    input_schema: {
      type: 'object' as const,
      properties: {
        product_id: { type: 'string', description: 'Product ID' },
      },
      required: ['product_id'],
    },
  },
];
```

```ts
// Agentic loop — keep going until Claude is done using tools
async function runAgent(userMessage: string): Promise<string> {
  const messages: Anthropic.MessageParam[] = [
    { role: 'user', content: userMessage },
  ];

  while (true) {
    const response = await anthropic.messages.create({
      model: 'claude-opus-4-8',
      max_tokens: 4096,
      tools,
      messages,
    });

    // If no tool use, return the text response
    if (response.stop_reason === 'end_turn') {
      return response.content
        .filter((b) => b.type === 'text')
        .map((b) => b.text)
        .join('');
    }

    // Process tool calls
    const toolUseBlocks = response.content.filter((b) => b.type === 'tool_use');
    const toolResults: Anthropic.ToolResultBlockParam[] = [];

    for (const block of toolUseBlocks) {
      if (block.type !== 'tool_use') continue;
      const result = await executeTool(block.name, block.input as Record<string, unknown>);
      toolResults.push({
        type: 'tool_result',
        tool_use_id: block.id,
        content: JSON.stringify(result),
      });
    }

    // Continue conversation with tool results
    messages.push({ role: 'assistant', content: response.content });
    messages.push({ role: 'user', content: toolResults });
  }
}

async function executeTool(name: string, input: Record<string, unknown>) {
  switch (name) {
    case 'search_products':
      return searchProducts(input.query as string, input.limit as number);
    case 'get_product_details':
      return getProductDetails(input.product_id as string);
    default:
      throw new Error(`Unknown tool: ${name}`);
  }
}
```

## Model selection

- **Claude Opus 4.8** — highest capability, best for complex reasoning and agentic tasks
- **Claude Sonnet 4.6** — strong capability, faster and cheaper, good default for most tasks
- **Claude Haiku 4.5** — fastest, cheapest, good for classification, short responses, high-volume tasks

Route model selection to the task, not the cost: use Haiku for bulk classification, Sonnet for typical completions, Opus for complex multi-step reasoning.
