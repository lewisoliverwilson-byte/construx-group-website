Zero config. No plugins. One command.

## Basic build

```bash
# Bundle a TypeScript entrypoint for the browser
bun build ./src/index.tsx --outdir ./dist --minify --sourcemap

# Multiple entrypoints
bun build ./src/app.tsx ./src/worker.ts --outdir ./dist --splitting

# Node target — for CLI tools or server bundles
bun build ./src/cli.ts --outdir ./dist --target node
```

## From `package.json`

```json
{
  "scripts": {
    "build":       "bun build ./src/index.tsx --outdir ./dist --minify --sourcemap",
    "build:watch": "bun build ./src/index.tsx --outdir ./dist --watch",
    "build:node":  "bun build ./src/server.ts --outdir ./dist --target node --minify"
  }
}
```

## Build API — in-process bundling

```ts
const result = await Bun.build({
  entrypoints: ['./src/index.tsx'],
  outdir:      './dist',
  minify:      true,
  sourcemap:   'external',
  splitting:   true,
  target:      'browser',
  define: {
    'process.env.NODE_ENV': '"production"',
    '__VERSION__':          `"${pkg.version}"`,
  },
  external: ['react', 'react-dom'],  // Don't bundle — peer deps
});

if (!result.success) {
  for (const log of result.logs) {
    console.error(log.message);
  }
  process.exit(1);
}

console.log(`Built ${result.outputs.length} files`);
```

## Plugins

```ts
const result = await Bun.build({
  entrypoints: ['./src/index.tsx'],
  outdir:      './dist',
  plugins: [
    {
      name: 'svg-loader',
      setup(build) {
        build.onLoad({ filter: /\.svg$/ }, async (args) => {
          const content = await Bun.file(args.path).text();
          return {
            contents: `export default ${JSON.stringify(content)}`,
            loader:   'js',
          };
        });
      },
    },
  ],
});
```

## Library build — multiple formats

```ts
// Build ESM + CJS from the same source
await Promise.all([
  Bun.build({
    entrypoints: ['./src/index.ts'],
    outdir:      './dist/esm',
    format:      'esm',
    minify:      true,
    external:    ['react'],
  }),
  Bun.build({
    entrypoints: ['./src/index.ts'],
    outdir:      './dist/cjs',
    format:      'cjs',
    minify:      true,
    external:    ['react'],
  }),
]);
```

## CSS bundling

```bash
bun build ./src/styles.css --outdir ./dist --minify
```

Bun handles CSS imports, `@import` resolution, and minification natively. No PostCSS config.

## Tree-shake report

```ts
const result = await Bun.build({
  entrypoints: ['./src/index.tsx'],
  outdir:      './dist',
  minify:      true,
});

for (const output of result.outputs) {
  console.log(`${output.path}: ${(output.size / 1024).toFixed(1)} kB`);
}
```

Bun vs esbuild: Bun's bundler is faster and has a cleaner API, but esbuild has a larger plugin ecosystem. Bun vs Vite: Vite is better for browser development (HMR, dev server); Bun's bundler is better for pure build steps with no dev server needed. The Construx default: Bun bundler for server bundles, CLI tools, and library builds; Vite for browser dev + build where HMR matters.
