SSE is HTTP with a persistent connection and a specific text format. The browser opens a connection to an SSE endpoint and keeps it open. The server sends text data in `data: ...\n\n` format. The browser's `EventSource` API fires events for each message. On disconnect, `EventSource` reconnects automatically.

## Server: Next.js API route

```ts
// app/api/events/route.ts
export async function GET(req: Request) {
  const encoder = new TextEncoder();

  const stream = new ReadableStream({
    async start(controller) {
      const send = (event: string, data: unknown) => {
        controller.enqueue(encoder.encode(`event: ${event}\n`));
        controller.enqueue(encoder.encode(`data: ${JSON.stringify(data)}\n\n`));
      };

      // Send initial state
      send('connected', { ts: Date.now() });

      // Stream live metrics every 2 seconds
      let count = 0;
      const interval = setInterval(() => {
        send('metrics', {
          cpu:  (40 + Math.random() * 20).toFixed(1),
          mem:  (62 + Math.random() * 8).toFixed(1),
          rps:  Math.floor(1200 + Math.random() * 400),
          ts:   Date.now(),
        });

        if (++count >= 100) {
          clearInterval(interval);
          controller.close();
        }
      }, 2000);

      // Clean up on client disconnect
      req.signal.addEventListener('abort', () => {
        clearInterval(interval);
        controller.close();
      });
    },
  });

  return new Response(stream, {
    headers: {
      'Content-Type':      'text/event-stream',
      'Cache-Control':     'no-cache, no-store',
      'Connection':        'keep-alive',
      'X-Accel-Buffering': 'no',  // disable nginx buffering
    },
  });
}
```

## Client: EventSource API

```ts
// Simple connection
const source = new EventSource('/api/events');

source.addEventListener('connected', (e) => {
  const data = JSON.parse(e.data);
  console.log('Connected at', data.ts);
});

source.addEventListener('metrics', (e) => {
  const { cpu, mem, rps } = JSON.parse(e.data);
  updateDashboard({ cpu, mem, rps });
});

source.onerror = (e) => {
  // EventSource reconnects automatically — you usually don't need to handle this
  console.warn('SSE error, reconnecting...');
};

// Clean up
source.close();
```

## SSE event format

```
# Named event
event: metrics
data: {"cpu": "42.3", "mem": "68.1"}

# Default event (no event: line)
data: hello world

# Multi-line data
data: first line
data: second line

# Event ID (browser includes in Last-Event-ID header on reconnect)
id: 1234
data: {"msg": "important"}

# Comment (keepalive — prevents proxies from closing idle connections)
: keepalive

```

Each event is separated by `\n\n`. Named events are handled by `addEventListener('event-name', ...)`. Unnamed events are handled by `source.onmessage`.

## React hook

```ts
// hooks/useEventSource.ts
import { useEffect, useState } from 'react';

export function useEventSource<T>(url: string, eventName: string) {
  const [data, setData] = useState<T | null>(null);
  const [error, setError] = useState<Event | null>(null);

  useEffect(() => {
    const source = new EventSource(url);

    source.addEventListener(eventName, (e: MessageEvent) => {
      setData(JSON.parse(e.data) as T);
    });

    source.onerror = (e) => setError(e);

    return () => source.close();
  }, [url, eventName]);

  return { data, error };
}

// Usage
function MetricsDashboard() {
  const { data } = useEventSource<{ cpu: string; rps: number }>(
    '/api/events',
    'metrics',
  );

  if (!data) return <Skeleton />;
  return <p>CPU: {data.cpu}% · RPS: {data.rps}</p>;
}
```

## Authenticated SSE

```ts
// SSE with auth: include credentials via fetch, then read the stream
async function createAuthenticatedSSE(url: string, token: string) {
  const response = await fetch(url, {
    headers: { Authorization: `Bearer ${token}` },
  });

  const reader  = response.body!.getReader();
  const decoder = new TextDecoder();
  let   buffer  = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });
    const events = buffer.split('\n\n');
    buffer = events.pop() ?? '';  // keep incomplete event in buffer

    for (const event of events) {
      const dataLine = event.split('\n').find((l) => l.startsWith('data: '));
      if (dataLine) {
        const data = JSON.parse(dataLine.slice(6));
        handleEvent(data);
      }
    }
  }
}
```

`EventSource` doesn't support custom headers. For authenticated SSE, use `fetch` with a readable stream instead.

## SSE vs WebSockets

| Feature                  | SSE                     | WebSockets              |
|--------------------------|-------------------------|-------------------------|
| Direction                | Server → Client only    | Bidirectional           |
| Protocol                 | HTTP                    | WS (upgrade from HTTP)  |
| Auto-reconnect           | Yes (built-in)          | Must implement manually |
| Load balancer support    | Usually fine            | Needs sticky sessions or pub/sub |
| Browser support          | All modern browsers     | All modern browsers     |

Use SSE for: notifications, live feeds, progress updates, AI token streaming. Use WebSockets for: chat, collaborative editing, multiplayer — anything that needs messages from client to server over the same connection.
