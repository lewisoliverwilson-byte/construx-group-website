Most email APIs feel like they were designed to host a marketing platform and an API was bolted on. Resend is the opposite.

## Install

```bash
npm install resend
```

## Send from a Next.js route handler

```ts
// src/app/api/send/route.ts
import { Resend } from 'resend';

const resend = new Resend(process.env.RESEND_API_KEY);

export async function POST(request: Request) {
  const { to, subject } = await request.json();

  const { data, error } = await resend.emails.send({
    from:    'Construx <hello@construxgroup.io>',
    to,
    subject,
    html:    '<p>Welcome to Construx.</p>',
  });

  if (error) return Response.json({ error }, { status: 500 });
  return Response.json({ id: data?.id }, { status: 201 });
}
```

## React email templates

```tsx
// emails/welcome.tsx
import {
  Html, Head, Body, Container, Heading, Text, Button, Hr
} from '@react-email/components';

interface WelcomeEmailProps {
  name:         string;
  workspaceUrl: string;
}

export default function WelcomeEmail({ name, workspaceUrl }: WelcomeEmailProps) {
  return (
    <Html>
      <Head />
      <Body style={{ fontFamily: 'sans-serif', background: '#fff' }}>
        <Container>
          <Heading>Welcome, {name}</Heading>
          <Text>Your workspace is ready.</Text>
          <Button href={workspaceUrl} style={{ background: '#F97316', color: '#fff', padding: '12px 20px' }}>
            Open workspace
          </Button>
          <Hr />
          <Text style={{ color: '#888', fontSize: '12px' }}>
            Sent by Construx Group · Unsubscribe
          </Text>
        </Container>
      </Body>
    </Html>
  );
}
```

```ts
// Use the React template with Resend
import { render } from '@react-email/render';
import WelcomeEmail from '@/emails/welcome';

const html = await render(
  <WelcomeEmail name="Lewis" workspaceUrl="https://app.construxgroup.io/w/abc" />,

  from:    'Construx <hello@construxgroup.io>',
  to:      'lewis@example.com',
  subject: 'Welcome to Construx',
  html,
});
```

## Webhooks

```ts
// src/app/api/webhooks/resend/route.ts
import { Webhook } from 'svix';

const wh = new Webhook(process.env.RESEND_WEBHOOK_SECRET!);

export async function POST(request: Request) {
  const payload = await request.text();
  const headers = Object.fromEntries(request.headers.entries());

  const event = wh.verify(payload, headers) as {
    type: string;
    data: { email_id: string; to: string[] };
  };

  if (event.type === 'email.bounced') {
    await markEmailBounced(event.data.to[0]);
  }

  return Response.json({ ok: true });
}
```

## Preview emails locally

```bash
npx react-email dev
```

Opens a local server at `localhost:3000` with a live preview of all templates in `emails/`. Hot-reloads on save. No sending required.

## Resend vs SendGrid vs Postmark

Resend: DX-first, React templates native, clean API, generous free tier (100 emails/day). SendGrid: enterprise feature set, complex pricing, more configuration overhead. Postmark: delivery-focused, transactional only, excellent for reliability. The Construx default: Resend for everything until you need SendGrid-level volume controls.
