Search implementations range from a simple `WHERE name LIKE '%query%'` to a hosted search engine with typo tolerance, faceting, and ML-powered ranking. The right choice depends on the size of your corpus, the quality demands, and whether you want to self-host.

## Postgres full-text search

For internal search, admin panels, or datasets under a few hundred thousand rows, Postgres FTS is often enough:

```sql
-- Add a tsvector column for fast search
ALTER TABLE products ADD COLUMN search_vector tsvector
  GENERATED ALWAYS AS (
    setweight(to_tsvector('english', coalesce(name, '')), 'A') ||
    setweight(to_tsvector('english', coalesce(description, '')), 'B') ||
    setweight(to_tsvector('english', coalesce(category, '')), 'C')
  ) STORED;

CREATE INDEX ON products USING GIN(search_vector);
```

```ts
// Query with ranking
const results = await db.execute(sql`
  SELECT *, ts_rank(search_vector, query) AS rank
  FROM products,
       plainto_tsquery('english', ${searchQuery}) query
  WHERE search_vector @@ query
  ORDER BY rank DESC
  LIMIT 20
`);
```

**Good for:** internal search, small-to-medium datasets, when you want zero additional infrastructure. **Not good for:** typo tolerance, faceted filtering by many attributes, instant-search at scale.

## Typesense

Typesense is an open-source search engine designed for instant-search UX — typo tolerant, sub-50ms responses, faceted filtering.

```bash
npm install typesense typesense-instantsearch-adapter
```

```ts
// lib/typesense.ts
import Typesense from 'typesense';

export const typesenseClient = new Typesense.Client({
  nodes: [{
    host:     process.env.TYPESENSE_HOST!,
    port:     443,
    protocol: 'https',
  }],
  apiKey:  process.env.TYPESENSE_API_KEY!,
  connectionTimeoutSeconds: 2,
});
```

```ts
// Create collection (schema)
await typesenseClient.collections().create({
  name:     'products',
  fields: [
    { name: 'id',          type: 'string' },
    { name: 'name',        type: 'string' },
    { name: 'description', type: 'string' },
    { name: 'price',       type: 'float'  },
    { name: 'category',    type: 'string', facet: true },
    { name: 'in_stock',    type: 'bool',   facet: true },
    { name: 'rating',      type: 'float'  },
  ],
  default_sorting_field: 'rating',
});
```

```ts
// Search with facets
const results = await typesenseClient.collections('products').documents().search({
  q:             'laptop stand',
  query_by:      'name,description',
  filter_by:     'in_stock:=true && price:<100',
  facet_by:      'category',
  sort_by:       'rating:desc',
  per_page:      20,
  typo_tokens_threshold: 1,
});
```

**Self-hosted Typesense** runs on a single server (DigitalOcean Droplet, EC2 instance). For high availability, run a cluster of 3 nodes. Typesense Cloud is the hosted option.

## Algolia

Algolia is the managed SaaS equivalent — same instant-search capability, no infrastructure to run, higher cost.

```bash
npm install algoliasearch instantsearch.js react-instantsearch
```

```ts
import algoliasearch from 'algoliasearch';

const client = algoliasearch(
  process.env.ALGOLIA_APP_ID!,
  process.env.ALGOLIA_ADMIN_KEY!,
);

const index = client.initIndex('products');

// Index documents
await index.saveObjects(products.map((p) => ({ ...p, objectID: p.id })));

// Search
const { hits } = await index.search('laptop stand', {
  filters:        'inStock:true AND price < 100',
  facets:         ['category'],
  hitsPerPage:    20,
});
```

**Advantages over Typesense:** zero infrastructure, global CDN, advanced AI ranking (Algolia NeuralSearch). **Disadvantages:** pricing scales with search volume (free tier is 10k requests/month), data leaves your infrastructure.

## What Construx uses

The Marqet's product search uses Typesense — 167,000+ listings, faceted filtering by category, price range, and in-stock status. Self-hosted on a 4GB DigitalOcean Droplet, indexed from Postgres via a sync job that runs on product updates. Response times are 8–25ms for most queries.

Postgres FTS is used in the journal search on this site — fewer than 600 documents, simple text matching, no infrastructure to maintain.

## The decision

- Under 50k documents, simple search: **Postgres FTS**
- Under 1M documents, need typo tolerance and faceting, want control: **Typesense self-hosted**
- Need managed infrastructure, enterprise SLAs, or AI ranking: **Algolia**
- Under 10k searches/month and want no infrastructure: **Algolia free tier**
