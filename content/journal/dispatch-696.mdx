If a step fails or the function times out, Workflow retries from the last successful step. You write a sequential function; Workflow makes it durable. No queue infrastructure, no worker processes — just your function deployed as an endpoint."

Serverless functions have a 10-30 second timeout. Long workflows — PDF generation, AI pipelines, multi-step data processing — don't fit. Upstash Workflow solves this by checkpointing each step. Your function reads like synchronous code; the runtime handles retries and persistence.

## Install

```bash
npm install @upstash/workflow
```

## Basic workflow

```ts
// app/api/workflow/onboarding/route.ts
import { serve } from '@upstash/workflow/nextjs';

export const { POST } = serve<{ userId: string; email: string }>(
  async (context) => {
    const { userId, email } = context.requestPayload;

    // Each step runs as a separate, retriable unit
    const user = await context.run('fetch-user', async () => {
      return db.users.findUniqueOrThrow({ where: { id: userId } });
    });

    await context.run('send-welcome-email', async () => {
      await resend.emails.send({
        to:      [email],
        subject: 'Welcome to Construx',
        react:   WelcomeEmail({ username: user.username }),
      });
    });

    // Wait 3 days before the next step — function exits and resumes
    await context.sleep('wait-3-days', 60 * 60 * 24 * 3);

    const hasSetup = await context.run('check-setup', async () => {
      const u = await db.users.findUniqueOrThrow({ where: { id: userId } });
      return u.profileComplete;
    });

    if (!hasSetup) {
      await context.run('send-reminder', async () => {
        await resend.emails.send({
          to:      [email],
          subject: 'Complete your Construx profile',
          react:   ReminderEmail({ username: user.username }),
        });
      });
    }
  },
);
```

## Trigger a workflow

```ts
// From any API route or Server Action
import { Client } from '@upstash/workflow';

const client = new Client({ token: process.env.QSTASH_TOKEN! });

await client.trigger({
  url:     'https://construxgroup.io/api/workflow/onboarding',
  body:    { userId: 'u_abc', email: 'lewis@construxgroup.io' },
  retries: 3,
});
```

## AI pipeline with streaming steps

```ts
// app/api/workflow/generate-report/route.ts
import { serve } from '@upstash/workflow/nextjs';

export const { POST } = serve<{ reportId: string }>(async (context) => {
  const { reportId } = context.requestPayload;

  // Step 1: gather raw data (DB query, may be slow)
  const rawData = await context.run('gather-data', async () => {
    return db.analytics.findMany({ where: { reportId }, take: 10000 });
  });

  // Step 2: AI summarisation (Claude API call, may timeout standalone)
  const summary = await context.run('ai-summarise', async () => {
    const { text } = await generateText({
      model:  anthropic('claude-opus-4-8'),
      prompt: `Summarise this analytics data: ${JSON.stringify(rawData)}`,
    });
    return text;
  });

  // Step 3: render and store PDF
  const pdfUrl = await context.run('render-pdf', async () => {
    const pdf = await renderPDF({ summary, rawData });
    return r2.upload(`reports/${reportId}.pdf`, pdf);
  });

  // Step 4: notify user
  await context.run('notify', async () => {
    await resend.emails.send({
      to:      [await db.reports.getOwnerEmail(reportId)],
      subject: 'Your report is ready',
      html:    `<a href="${pdfUrl}">Download report</a>`,
    });
  });
});
```

## Error handling and retries

```ts
await context.run('send-email', async () => {
  const result = await resend.emails.send({ to: [email], ... });
  if (result.error) throw new Error(result.error.message);
  // If this throws, Workflow retries this step with exponential backoff
  // Previous steps are NOT re-run — they are checkpointed
});
```

## Upstash Workflow vs BullMQ vs Inngest vs Temporal

Upstash Workflow: serverless-native, no infrastructure, QStash-backed, sleep for days between steps. BullMQ: Redis-backed, requires a worker process, excellent for high-throughput queues, not serverless-native. Inngest: similar to Workflow, hosted, rich dashboard, TypeScript-first. Temporal: enterprise-grade durable execution engine, complex setup, extremely powerful. Use Upstash Workflow when you are already on Upstash and want durable jobs in a serverless environment without running workers.
