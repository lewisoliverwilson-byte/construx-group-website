date: "2032-08-22"
excerpt: "fzf is an interactive fuzzy finder for the terminal — it reads lines from stdin, renders an interactive selection UI, and writes the chosen line to stdout. The killer feature is the shell integration: Ctrl+R replaces the default bash/zsh history search with a full-screen fuzzy search over your entire command history; Alt+C drops into a fuzzy directory picker; Tab completion for kill, ssh, and git checkout all use fzf. The preview window (--preview) runs an arbitrary command for each item — typically bat for files or git log for commits. fzf is fast enough to filter millions of lines interactively because it uses a parallel multi-threaded search with a score-based ranking algorithm (Smith-Waterman affine gap scoring adapted for fuzzy matching)."

Fuzzy-filter anything. Preview with `bat`. Wire into every completion. Use `--multi` to select several.

## Shell integration and Ctrl+R

```bash
# Install and add shell integration (bash/zsh)
# After install, add to ~/.bashrc or ~/.zshrc:
eval "$(fzf --bash)"   # bash
eval "$(fzf --zsh)"    # zsh (or source /usr/share/fzf/key-bindings.zsh)

# Key bindings added by shell integration:
# Ctrl+R   → fuzzy search over shell history (replaces default Ctrl+R)
# Ctrl+T   → fuzzy file picker — inserts selected path at cursor
# Alt+C    → fuzzy cd — changes directory to selected

# Ctrl+R: history search
# Type partial command → fzf filters in real time → Enter to run
# All history, not just the last 500 entries
# Works across tmux panes if HISTFILE is shared

# Make history larger so Ctrl+R is more useful:
echo 'HISTSIZE=100000' >> ~/.bashrc
echo 'HISTFILESIZE=100000' >> ~/.bashrc
echo 'HISTCONTROL=ignoredups:erasedups' >> ~/.bashrc
echo 'shopt -s histappend' >> ~/.bashrc
```

## File and directory navigation

```bash
# Basic: fuzzy-filter a list of files and open selected in $EDITOR
fzf | xargs $EDITOR

# With preview: show file content alongside the selector
fzf --preview 'bat --color=always --style=numbers {}' \
    --preview-window 'right:60%'

# Only show files (not directories), hidden files included
find . -type f | fzf --preview 'bat --color=always {}'

# fd (fast find) + fzf — respects .gitignore by default
fd --type f | fzf --preview 'bat --color=always {}'

# Fuzzy-cd: jump to any subdirectory
cd $(find . -type d | fzf)

# Or use the built-in Alt+C binding after shell integration
# Alt+C → interactive directory picker → cd on Enter

# Open a recently modified file (last 7 days)
find . -type f -mtime -7 | fzf --preview 'bat --color=always {}' | xargs $EDITOR

# Select multiple files (--multi / -m) → open all in editor
fzf --multi --preview 'bat --color=always {}' | xargs $EDITOR
```

## Process management with fzf

```bash
# Interactive kill: fuzzy-select a process → send SIGTERM
kill $(ps aux | fzf --header-lines=1 | awk '{print $2}')

# Kill with SIGKILL for unresponsive processes
kill -9 $(ps aux | fzf --header-lines=1 | awk '{print $2}')

# Better: fzf-based process killer with preview showing process details
ps aux --sort=-%cpu | fzf \
    --header-lines=1 \
    --preview 'echo {} | awk "{print \$2}" | xargs -I{} cat /proc/{}/status 2>/dev/null | head -20' \
    --preview-window 'right:40%' | \
    awk '{print $2}' | xargs kill

# Docker: fuzzy-select a container to attach to
docker ps | fzf --header-lines=1 | awk '{print $1}' | xargs docker exec -it sh

# Docker: fuzzy-select and remove stopped containers
docker ps -a --filter status=exited | \
    fzf --header-lines=1 --multi | \
    awk '{print $1}' | xargs docker rm
```

## Git integration

```bash
# Fuzzy git branch checkout
git checkout $(git branch -a | fzf | sed 's/remotes\/origin\///')

# Fuzzy commit selection with diff preview
git log --oneline | fzf \
    --preview 'git show --stat --color=always {1}' \
    --preview-window 'right:60%' | \
    awk '{print $1}'

# Fuzzy add: select unstaged files to stage
git diff --name-only | fzf --multi | xargs git add

# Fuzzy stash apply
git stash list | fzf \
    --preview 'git stash show -p {1} --color=always' \
    --preview-window 'right:60%' | \
    awk -F: '{print $1}' | xargs git stash apply

# Fuzzy git log with full patch preview (slow on large repos)
git log --oneline --all | fzf \
    --ansi \
    --preview 'git show {1} --color=always' \
    --preview-window 'right:70%:wrap'

# Fuzzy select and checkout PR branch (requires gh CLI)
gh pr list | fzf | awk '{print $1}' | xargs gh pr checkout
```

## fzf in scripts and pipelines

```bash
# fzf reads from stdin, writes selection to stdout — compose freely
# Select a Kubernetes pod to exec into
kubectl get pods -n construx | \
    fzf --header-lines=1 \
        --preview 'kubectl logs {1} -n construx --tail=20 --color=always' | \
    awk '{print $1}' | \
    xargs -I{} kubectl exec -it {} -n construx -- sh

# Select a log file and tail it
ls /var/log/ | fzf | xargs -I{} tail -f /var/log/{}

# Select an SSH host from ~/.ssh/config
grep "^Host " ~/.ssh/config | awk '{print $2}' | fzf | xargs ssh

# fzf with --bind: custom keybindings inside the selector
# Ctrl+Y → copy selection to clipboard (xclip / pbcopy)
fzf --bind 'ctrl-y:execute-silent(echo {} | xclip -selection clipboard)'

# Ctrl+E → open selection in $EDITOR
fzf --bind 'ctrl-e:execute($EDITOR {} < /dev/tty > /dev/tty)'

# --print0 / xargs -0: handle filenames with spaces safely
find . -name "*.log" -print0 | fzf --read0 --print0 | xargs -0 less
```

## FZF_DEFAULT_OPTS and configuration

```bash
# ~/.bashrc or ~/.zshrc — tune fzf defaults
export FZF_DEFAULT_COMMAND='fd --type f --hidden --follow --exclude .git'
export FZF_CTRL_T_COMMAND="$FZF_DEFAULT_COMMAND"
export FZF_ALT_C_COMMAND='fd --type d --hidden --follow --exclude .git'

export FZF_DEFAULT_OPTS="
  --height 40%
  --layout=reverse
  --border
  --info=inline
  --preview-window=right:50%:wrap
  --color=bg+:#1e1e2e,bg:#181825,spinner:#f5e0dc,hl:#f38ba8
  --color=fg:#cdd6f4,header:#f38ba8,info:#cba6f7,pointer:#f5e0dc
  --color=marker:#f5e0dc,fg+:#cdd6f4,prompt:#cba6f7,hl+:#f38ba8
  --bind ctrl-d:preview-down,ctrl-u:preview-up
  --bind ctrl-f:page-down,ctrl-b:page-up
"

# FZF_CTRL_R_OPTS: tune history search specifically
export FZF_CTRL_R_OPTS="
  --preview 'echo {}'
  --preview-window up:3:hidden:wrap
  --bind 'ctrl-/:toggle-preview'
  --bind 'ctrl-y:execute-silent(echo -n {2..} | xclip -selection clipboard)+abort'
  --color header:italic
  --header 'Press CTRL-Y to copy command into clipboard'
"
```

fzf vs dmenu vs rofi: dmenu and rofi are X11-native launchers — great for window manager integration but need a display server. fzf lives in the terminal — compose it with any command that produces lines. The mental model: fzf is `grep` but interactive and fuzzy. Anything you'd pipe through `grep` or `awk | head` to select one item from a list is a candidate for fzf. The preview window turns it into a lightweight file explorer, log viewer, or git history browser without learning a dedicated tool. The one limitation: large inputs (>1M lines) introduce latency — use fd instead of find for file listing, and consider `--nth` to restrict which fields fzf scores against.
