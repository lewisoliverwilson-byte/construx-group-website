Webpack made bundling fast. Vite made it unnecessary during development.

## Create a project

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm run dev
```

## vite.config.ts

```ts
import { defineConfig }   from 'vite';
import react              from '@vitejs/plugin-react';
import { resolve }        from 'path';
import tsconfigPaths      from 'vite-tsconfig-paths';
import { visualizer }     from 'rollup-plugin-visualizer';

export default defineConfig(({ command, mode }) => ({
  plugins: [
    react({
      babel: {
        plugins: [['babel-plugin-react-compiler', {}]],
      },
    }),
    tsconfigPaths(),
    mode === 'analyze' && visualizer({ open: true, gzipSize: true }),
  ],

  resolve: {
    alias: {
      '@': resolve(__dirname, './src'),
    },
  },

  build: {
    target:      'es2022',
    sourcemap:   true,
    rollupOptions: {
      output: {
        manualChunks: {
          vendor:       ['react', 'react-dom'],
          'tanstack':   ['@tanstack/react-query'],
          'ui':         ['lucide-react'],
        },
      },
    },
  },

  server: {
    port:   3000,
    proxy: {
      '/api': {
        target:    'http://localhost:8787',
        changeOrigin: true,
      },
    },
  },

  preview: {
    port: 4173,
  },
}));
```

## Environment API (Vite 6)

```ts
// vite.config.ts — Vite 6
import { defineConfig } from 'vite';

export default defineConfig({
  environments: {
    client: {
      // Browser environment — native ESM
      build: { outDir: 'dist/client' },
    },
    ssr: {
      // Node.js SSR environment
      build: {
        outDir: 'dist/server',
        target: 'node22',
      },
      resolve: {
        conditions: ['node', 'import', 'module'],
      },
    },
    edge: {
      // Cloudflare Workers environment
      build: {
        outDir: 'dist/edge',
        target: 'es2022',
      },
      resolve: {
        conditions: ['workerd', 'browser', 'import'],
      },
    },
  },
});
```

The Environment API lets a single Vite config produce multiple builds with different target environments and module resolution rules.

```bash
# Analyze bundle

```

## Vite vs Turbopack vs esbuild

Vite: native ESM dev server, Rollup production build, broad ecosystem, works with any framework. Turbopack: Rust-powered, integrated into Next.js 15, not standalone. esbuild: fastest bundler but limited configuration, no SSR, best as a plugin in Vite. For non-Next.js React projects: Vite. For Next.js: Turbopack (built in). For scripts and CLIs: esbuild or tsx.
