Uploading files through your API server is fine for small files and low volume. For user-generated content (images, documents, videos), you want direct browser→S3 uploads. The server only generates the credential.

## Install

```bash
npm install @aws-sdk/client-s3 @aws-sdk/s3-request-presigner
```

## Generate a presigned upload URL (server)

```ts
// app/api/upload/route.ts
import { S3Client, PutObjectCommand } from '@aws-sdk/client-s3';
import { getSignedUrl }               from '@aws-sdk/s3-request-presigner';
import { randomUUID }                  from 'crypto';
import { z }                           from 'zod';

const s3 = new S3Client({
  region:      process.env.AWS_REGION!,
  credentials: {
    accessKeyId:     process.env.AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
  },
});

const UploadSchema = z.object({
  filename:    z.string().max(200),
  contentType: z.enum(['image/jpeg', 'image/png', 'image/webp', 'application/pdf']),
  size:        z.number().max(10 * 1024 * 1024),  // 10 MB max
});

export async function POST(req: Request) {
  const session = await getSession();
  if (!session) return new Response('Unauthorized', { status: 401 });

  const body   = await req.json();
  const parsed = UploadSchema.safeParse(body);
  if (!parsed.success) return Response.json({ error: parsed.error.flatten() }, { status: 400 });

  const { filename, contentType, size } = parsed.data;
  const key    = `uploads/${session.user.id}/${randomUUID()}/${filename}`;

  const command = new PutObjectCommand({
    Bucket:        process.env.S3_BUCKET!,
    Key:           key,
    ContentType:   contentType,
    ContentLength: size,
    Metadata:      { userId: session.user.id, originalName: filename },
  });

  const url = await getSignedUrl(s3, command, { expiresIn: 300 });  // 5 minutes

  return Response.json({ url, key });
}
```

## Upload from the client

```tsx
'use client';
import { useState } from 'react';

export function FileUploader({ onComplete }: { onComplete: (key: string) => void }) {
  const [status, setStatus] = useState('');
  const [progress, setProgress] = useState(0);

  const handleFile = async (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (!file) return;

    setStatus('Getting upload URL…');

    // 1. Get presigned URL from your server
    const res = await fetch('/api/upload', {
      method:  'POST',
      headers: { 'Content-Type': 'application/json' },
      body:    JSON.stringify({
        filename:    file.name,
        contentType: file.type,
        size:        file.size,
      }),
    });

    const { url, key } = await res.json();
    setStatus('Uploading…');

    // 2. Upload directly to S3 using the presigned URL
    const xhr = new XMLHttpRequest();
    xhr.upload.onprogress = (e) => {
      if (e.lengthComputable) setProgress(Math.round((e.loaded / e.total) * 100));
    };

    await new Promise<void>((resolve, reject) => {
      xhr.open('PUT', url);
      xhr.setRequestHeader('Content-Type', file.type);
      xhr.onload   = () => xhr.status === 200 ? resolve() : reject(new Error(`S3 ${xhr.status}`));
      xhr.onerror  = () => reject(new Error('Upload failed'));
      xhr.send(file);
    });

    setStatus('Done');
    onComplete(key);
  };

  return (
    <div>
      <input type="file" accept="image/*,application/pdf" onChange={handleFile} />
      {status && <p>{status} {progress > 0 && progress < 100 ? `${progress}%` : ''}</p>}
    </div>
  );
}
```


## S3 vs Cloudflare R2 vs Uploadthing

S3: standard, all ecosystem tools support it, egress fees. R2: S3-compatible, zero egress fees, Cloudflare CDN native. Uploadthing: managed upload service, hooks for Next.js, no S3 config needed, more expensive at scale. Use R2 if you are on Cloudflare and egress cost is a concern. Use S3 when you need the broadest ecosystem compatibility. Use Uploadthing for a fast-moving project where you do not want to configure S3 policies.
