Node.js is fine. Bun is faster at almost everything and does more with less setup. For new projects, the choice is straightforward.

## Install and run

```bash
curl -fsSL https://bun.sh/install | bash

# Run TypeScript directly
bun run script.ts

# Drop-in Node.js replacement
bun run src/server.ts

# Package manager (faster than npm/pnpm)
bun install
bun add zod
bun add -d @types/node

# Run package.json scripts
bun dev
bun build
bun test
```

## Bun as a package manager

```bash
# Install dependencies (reads package.json)
bun install
# → done in 340ms

# vs npm install
# → done in 8.2s

# vs pnpm install
# → done in 2.1s
```

Bun uses a binary lockfile (`bun.lockb`) instead of `package-lock.json`. Faster reads, smaller file size. The tradeoff: it is not human-readable. Use `bun install --frozen-lockfile` in CI.

## Built-in test runner

```ts
// math.test.ts
import { test, expect, describe } from 'bun:test';
import { add, multiply } from './math';

describe('math', () => {
  test('adds numbers', () => {
    expect(add(2, 3)).toBe(5);
  });

  test('multiplies numbers', () => {
    expect(multiply(4, 5)).toBe(20);
  });
});
```

```bash
bun test
# → math.test.ts
# ✓ adds numbers [0.12ms]
# ✓ multiplies numbers [0.08ms]
# 2 pass, 0 fail
```

The test runner is compatible with Jest's API (`describe`, `test`, `expect`, `mock`, `spyOn`). Migrate from Jest by replacing `jest` with `bun:test` in imports.

## Bun.serve — built-in HTTP server

```ts
// server.ts
const server = Bun.serve({
  port: 3000,

  fetch(req) {
    const url = new URL(req.url);

    if (url.pathname === '/health') {
      return new Response(JSON.stringify({ status: 'ok' }), {
        headers: { 'Content-Type': 'application/json' },
      });
    }

    return new Response('Not Found', { status: 404 });
  },
});

console.log(`Listening on http://localhost:${server.port}`);
```

```bash
bun run server.ts
```

No Express, no Fastify, no `http.createServer`. Bun.serve handles 200k+ requests/second on a single core.

## Bun Shell

```ts
import { $ } from 'bun';

const branch = await $`git branch --show-current`.text();
const files  = await $`ls -la src/`.lines();
const count  = await $`wc -l src/**/*.ts`.json();

console.log(`Branch: ${branch.trim()}`);
console.log(`Files: ${files.length}`);
```

`$` is a tagged template literal that runs shell commands. Cross-platform (works on Windows), no child_process boilerplate.

## When to use Bun

Use Bun for: new projects, scripts and CLIs, projects where install speed matters, TypeScript projects that do not need tsc. Keep Node.js for: projects with native modules that have not updated, frameworks that explicitly require Node (some do), monorepos where mixed runtime causes problems.

The compatibility gap is closing. Bun tracks the Node.js API surface and fixes compatibility issues with each release. For 2030, greenfield Bun is the right default.
