date: "2032-05-24"
excerpt: "Restic is a backup tool written in Go that provides encrypted, deduplicated, content-addressed snapshots to any backend: S3, Backblaze B2, SFTP, local disk, or Rclone-supported storage. Every backup creates a snapshot of a directory; deduplication ensures unchanged data is never re-transmitted (only new data is uploaded). Chunks are encrypted with AES-256 before leaving your machine — the backend never sees plaintext. Restic's repository format enables fast differential restores: you can restore a single file from three months ago without downloading the full backup."

Encrypt before upload. Deduplicate at the chunk level. Restore a single file from any snapshot.

## Initialising and creating backups

```bash
# Install Restic
brew install restic   # macOS
apt-get install restic  # Debian/Ubuntu

# Initialise a repository — S3 backend
export AWS_ACCESS_KEY_ID="AKIAXXXXXXXXXXXXXXXX"
export AWS_SECRET_ACCESS_KEY="xxxxxxxxxxxxxxxxxx"
export RESTIC_REPOSITORY="s3:s3.amazonaws.com/construx-backups/restic"
export RESTIC_PASSWORD="$(cat ~/.restic-password)"   # Master encryption password

restic init
# created restic repository 8f9e3a2b1c4d at s3:s3.amazonaws.com/construx-backups/restic

# First backup — uploads all chunks
restic backup /var/lib/postgresql/data \
  --tag postgres \
  --tag prod \
  --exclude "*.pid"

# snapshot 3a7f2c1d saved
# Files:        8,241 new,    0 changed,    0 unmodified
# Added to the repository: 2.847 GiB (after deduplication)

# Second backup — only new/changed chunks uploaded
restic backup /var/lib/postgresql/data --tag postgres --tag prod
# snapshot c8b4a9e2 saved
# Files:           0 new,   42 changed,    8,199 unmodified
# Added to the repository: 124.8 MiB  ← only the delta

# Backup with exclusions and host tag
restic backup \
  /home/lewis \
  --exclude-file ~/.restic-exclude \   # List of glob patterns to exclude
  --tag workstation \
  --host lewis-mbp \
  --one-file-system                    # Don't cross mount points

# ~/.restic-exclude:
# node_modules
# .cache
# .npm
# **/__pycache__
# *.tmp
```

## Snapshot management and listing

```bash
# List all snapshots
restic snapshots
# ID        Time                 Host         Tags         Paths
# 3a7f2c1d  2032-05-21 02:00:41  prod-01      postgres     /var/lib/postgresql/data
# c8b4a9e2  2032-05-22 02:00:38  prod-01      postgres     /var/lib/postgresql/data
# d9e1b7f3  2032-05-23 02:00:42  prod-01      postgres     /var/lib/postgresql/data

# Filter snapshots
restic snapshots --tag postgres --host prod-01

# Show repository statistics
restic stats --mode restore-size
# Stats in restore-size mode:
#   Total File Count:   8,241
#   Total Size:         2.847 GiB
#
# restic stats --mode raw-data
#   Raw Size:           312.4 MiB  ← actual bytes in repository (after dedup + compression)
#   Compression ratio:  9.1x

# Check repository integrity
restic check --read-data-subset=1%   # Verify 1% of chunks (fast, still catches corruption)
# no errors were found

# Forget old snapshots with retention policy
restic forget \
  --keep-daily 7 \        # Keep last 7 daily snapshots
  --keep-weekly 4 \       # Keep last 4 weekly
  --keep-monthly 6 \      # Keep last 6 monthly
  --prune                 # Actually delete unreferenced data from the repo
# remove 12 snapshots, remove 8,341 data blobs, reclaim 486.2 MiB
```

## Restoring and browsing snapshots

```bash
# Restore entire snapshot to a directory
restic restore 3a7f2c1d --target /tmp/restore-test

# Restore to the original path (disaster recovery)
systemctl stop postgresql
restic restore latest --tag postgres --target / --verify
systemctl start postgresql

# Restore a single file from a snapshot (without downloading everything)
restic restore 3a7f2c1d \
  --include "/var/lib/postgresql/data/pg_hba.conf" \
  --target /tmp/restore/

# Mount the repository as a FUSE filesystem (browse any snapshot)
restic mount /mnt/restic-snapshots &
ls /mnt/restic-snapshots/
# hosts/  ids/  snapshots/  tags/

ls /mnt/restic-snapshots/snapshots/latest/
# postgresql/  (the full directory tree from the snapshot)

# Browse a specific snapshot
ls /mnt/restic-snapshots/ids/3a7f2c1d/var/lib/postgresql/data/

# Useful for finding when a file was last changed
ls -la /mnt/restic-snapshots/snapshots/*/var/lib/postgresql/data/pg_hba.conf

umount /mnt/restic-snapshots
```

## Automation — systemd timer for daily backups

```ini
# /etc/systemd/system/restic-backup.service
[Unit]
Description=Restic backup — PostgreSQL data
After=network.target

[Service]
Type=oneshot
User=root
EnvironmentFile=/etc/restic/env   # Contains RESTIC_REPOSITORY and RESTIC_PASSWORD
ExecStartPre=/usr/bin/restic unlock --remove-all  # Clear stale locks
ExecStart=/usr/bin/restic backup \
    /var/lib/postgresql/data \
    --tag postgres \
    --tag prod \
    --exclude "*.pid" \
    --json >> /var/log/restic.log 2>&1
ExecStartPost=/usr/bin/restic forget \
    --keep-daily 7 \
    --keep-weekly 4 \
    --keep-monthly 6 \
    --prune \
    --json >> /var/log/restic.log 2>&1
# Alert on failure via systemd-email or external notification
OnFailure=notify-failed@%n.service

# /etc/systemd/system/restic-backup.timer
[Unit]
Description=Daily Restic backup at 02:00

[Timer]
OnCalendar=*-*-* 02:00:00
RandomizedDelaySec=300   # Spread 5min random delay to avoid thundering herd
Persistent=true          # Run if system was off at scheduled time

[Install]
WantedBy=timers.target
```

Restic vs rsync for backups: rsync copies files — it's efficient for syncing directories but doesn't maintain backup history (old versions get overwritten), has no encryption, and no deduplication across snapshots. Restic maintains a full snapshot history with deduplication — a month of daily backups doesn't use 30x the storage of one backup, because unchanged chunks are stored once and referenced. The encryption is critical: Restic encrypts before upload, so S3 breach exposure is zero — the backup repository is useless without the password. Restic's limitation vs enterprise tools: no support for application-consistent backups (Postgres WAL consistency requires a pre-backup checkpoint hook).
