Open Graph images are the preview cards that appear when you share a link on social platforms, in Slack, in iMessage. They're the first impression of any piece of content shared outside the site. Most auto-generated ones are generic and forgettable.

Here's how we build dynamic OG images that look intentional.

## The Next.js ImageResponse API

Next.js exposes an `ImageResponse` API in the App Router that renders JSX to a PNG using Satori (a library that converts HTML/CSS to SVG, then to PNG). The key advantage: you write JSX, not canvas API calls.

The convention: create an `opengraph-image.tsx` file in your route segment. For journal posts:

```
app/journal/[slug]/opengraph-image.tsx
```

This file generates a 1200×630 image for each post. It's called at build time (for static generation) or at request time (for dynamic content).

## Our implementation

```tsx
import { ImageResponse } from 'next/og';
import { getAllPostMeta } from '@/lib/posts';

export const size = { width: 1200, height: 630 };
export const contentType = 'image/png';

  const allPosts = getAllPostMeta();
  const post = allPosts.find((p) => p.slug === params.slug);

  // Truncate to fit within the image bounds
  const title = post?.title
    ? post.title.length > 70
      ? post.title.slice(0, 67) + '...'
      : post.title
    : 'Construx Group Journal';

  const excerpt = post?.excerpt
    ? post.excerpt.length > 130
      ? post.excerpt.slice(0, 127) + '...'
      : post.excerpt
    : 'Build-in-public dispatches from the Construx ventures.';

  const dispatchNum = post
    ? String(allPosts.length - allPosts.findIndex((p) => p.slug === params.slug)).padStart(3, '0')
    : '---';

  const TAG_COLORS: Record<string, string> = {
    Strategy: '#F97316',
    'Build Log': '#4ade80',
    Product: '#7dd3fc',
    Methodology: '#a78bfa',
    Process: '#67e8f9',
  };
  const tagColor = TAG_COLORS[tagLabel] ?? '#F97316';

  return new ImageResponse(
    (
      <div
        style={{
          width: '1200px',
          height: '630px',
          background: '#000006',
          display: 'flex',
          flexDirection: 'column',
          position: 'relative',
          overflow: 'hidden',
          fontFamily: 'monospace',
        }}
      >

          style={{
            position: 'absolute',
            inset: 0,

            backgroundSize: '40px 40px',
          }}
        />

        {/* Orange radial glow */}
        <div
          style={{
            position: 'absolute',
            top: '-200px',
            left: '-100px',
            width: '600px',
            height: '600px',
            background: 'radial-gradient(circle, rgba(249,115,22,0.12) 0%, transparent 70%)',
          }}
        />

        {/* Top accent bar */}
        <div
          style={{
            position: 'absolute',
            top: 0,
            left: 0,
            right: 0,
            height: '3px',
            background: 'linear-gradient(90deg, #F97316, #FB923C, transparent)',
          }}
        />

        {/* Content area */}
        <div
          style={{
            display: 'flex',
            flexDirection: 'column',
            padding: '56px 64px',
            flex: 1,
          }}
        >
          {/* Header row: logo + dispatch number */}
          <div
            style={{

              marginBottom: '40px',
            }}

            <div style={{ display: 'flex', alignItems: 'center', gap: '12px' }}>
              <div
                style={{
                  width: '36px',
                  height: '36px',
                  background: '#F97316',
                  borderRadius: '4px',
                  display: 'flex',
                  alignItems: 'center',
                  justifyContent: 'center',
                  fontWeight: 700,
                  fontSize: '14px',
                  color: '#000',
                  fontFamily: 'monospace',
                }}
              >
                CX
              </div>

                </span>
              </div>

          {/* Tag */}
          <div
            style={{
              display: 'flex',
              alignItems: 'center',
              gap: '8px',
              marginBottom: '20px',
            }}
          >
            <span
              style={{
                fontFamily: 'monospace',
                fontSize: '11px',
                color: tagColor,
                background: `${tagColor}1a`,

              }}

              {tagLabel}

          {/* Title */}

              fontSize: '42px',

          </div>

        {/* Bottom bar */}
        <div
          style={{
            display: 'flex',
            alignItems: 'center',
            justifyContent: 'space-between',

            BUILD IN PUBLIC · AI FIRST
          </span>
        </div>
      </div>
    ),
    { ...size },
  );
}
```

## What makes this work visually

**Consistent with the site brand.** The same dark background, orange accent, grid overlay, and monospace type that characterises the site appears in the OG image. A reader who's seen the site before recognises it immediately.

**Dispatch number as identity.** The `#152` in the top-right corner is distinctive — it signals that this is a specific entry in a series, not a one-off piece.

**Tag with colour coding.** The tag label uses the same colour system as the site (orange for Strategy, green for Build Log, etc.). This communicates the content type visually before any text is read.

**Title at readable size.** 42px is large enough to read in a thumbnail. We truncate to ~70 characters to prevent overflow.

## Performance

ImageResponse generates the PNG at request time for dynamic routes. For our journal with 150+ posts, static generation at build time would produce 150+ PNG files but eliminate any runtime latency.

We use dynamic generation because: (1) it avoids increasing build time proportionally with post count, and (2) OG images are cached by social platforms after first access, so the "first request" latency only affects the first person who shares each post.

For very high-traffic posts, the OG image is already cached by the platform before volume picks up. Runtime latency for OG image generation is essentially invisible in practice.
