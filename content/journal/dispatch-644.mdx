Most email APIs were built for marketing teams. Resend is built for engineers. The SDK matches TypeScript patterns, the dashboard shows per-email delivery status, and the React Email integration makes templates composable.

## Setup

```bash
npm install resend @react-email/components
```

## Sending a simple email

```ts
import { resend } from '@/lib/resend';

const { data, error } = await resend.emails.send({
  from:    'Construx <hello@construxgroup.io>',
  to:      ['lewis@construxgroup.io'],
  subject: 'Welcome to Construx',
  text:    'Thanks for joining. We are glad to have you.',
  html:    '<p>Thanks for joining. We are glad to have you.</p>',
});

if (error) {
  console.error('Email failed:', error);
}
```

## Sending with a React template

```ts
import { render }       from '@react-email/render';
import { resend }       from '@/lib/resend';
import { WelcomeEmail } from '@/emails/WelcomeEmail';

export async function sendWelcomeEmail(user: { email: string; firstName: string }) {
  const html = render(
    <WelcomeEmail
      firstName={user.firstName}
      loginUrl={`https://construxgroup.io/login`}
    />,
  );

  const { data, error } = await resend.emails.send({
    from:    'Construx <welcome@construxgroup.io>',
    to:      [user.email],
    subject: `Welcome to Construx, ${user.firstName}`,
    html,
  });

  if (error) throw new Error(`Email delivery failed: ${error.message}`);
  return data!.id;
}
```

## Batch sending

```ts
// Send to multiple recipients in one API call
const { data, error } = await resend.batch.send([
  {
    from:    'Construx <noreply@construxgroup.io>',
    to:      ['user1@example.com'],
    subject: 'Your order shipped',
    html:    orderEmailHtml('order-123'),
  },
  {
    from:    'Construx <noreply@construxgroup.io>',
    to:      ['user2@example.com'],
    subject: 'Your order shipped',
    html:    orderEmailHtml('order-456'),
  },
]);
```

Batch send up to 100 emails per API call. Each email is processed independently — one failure doesn't block others.

## Webhooks: delivery events

```ts
// app/api/webhooks/resend/route.ts
import { Resend }      from 'resend';
import { db }          from '@/db';

const resend = new Resend(process.env.RESEND_API_KEY);

export async function POST(req: Request) {
  const payload   = await req.json();
  const signature = req.headers.get('svix-signature') ?? '';

  // Verify webhook signature
  const event = await resend.webhooks.verify(payload, signature);

  switch (event.type) {
    case 'email.delivered':
      await db.emailLog.update({
        where: { resendId: event.data.email_id },
        data:  { status: 'delivered', deliveredAt: new Date() },
      });
      break;
    case 'email.bounced':
      await db.emailLog.update({
        where: { resendId: event.data.email_id },
        data:  { status: 'bounced', bouncedAt: new Date() },
      });
      // Mark email as undeliverable
      await markEmailUndeliverable(event.data.to);
      break;
    case 'email.complained':
      await unsubscribeUser(event.data.to);
      break;
  }

  return Response.json({ ok: true });
}
```

## Domain setup

```bash
# In Resend dashboard: add domain → copy DNS records → add to your DNS provider

# Verify
dig TXT _dmarc.construxgroup.io
dig TXT construxgroup.io       # SPF record
dig TXT resend._domainkey.construxgroup.io  # DKIM
```

Add the Resend DKIM records to your DNS, set up SPF, configure DMARC. Once all three pass, Resend marks your domain as verified and emails land in inbox rather than spam.
