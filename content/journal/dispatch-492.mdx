Email infrastructure is deeply unsexy and deeply important. Every product eventually needs to send emails — password resets, purchase receipts, onboarding sequences, notification digests. The legacy approach (configure Postfix, manage SPF/DKIM/DMARC, fight with deliverability) is a maintenance burden. Resend wraps all of that in an API with good deliverability defaults and a React-based templating library.

## Setup

```bash
npm install resend
npm install react-email @react-email/components -D
```

```ts
// lib/resend.ts
import { Resend } from 'resend';

export const resend = new Resend(process.env.RESEND_API_KEY!);
```

Add the API key to your environment:
```
RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## Sending a basic email

```ts
// app/api/contact/route.ts
import { resend } from '@/lib/resend';

export async function POST(req: Request) {
  const { name, email, message } = await req.json();

  const { data, error } = await resend.emails.send({
    from:    'Construx Group <hello@construxgroup.io>',
    to:      ['lewis@construxgroup.io'],
    replyTo: email,
    subject: `Contact form: ${name}`,
    html:    `<p><strong>${name}</strong> (${email}):</p><p>${message}</p>`,
  });

  if (error) {
    console.error('Resend error:', error);
    return Response.json({ error: 'Failed to send' }, { status: 500 });
  }

  return Response.json({ id: data?.id });
}
```

The `from` domain (`construxgroup.io`) needs to be verified in Resend's dashboard — you add three DNS records (SPF, DKIM, DMARC) and Resend handles the reputation layer. First-time setup takes about 10 minutes.

## React Email templates

React Email lets you write email templates as React components with a subset of HTML and inline styles that render consistently across email clients:

```tsx
// emails/WelcomeEmail.tsx
import {
  Body,
  Button,
  Container,
  Head,
  Heading,
  Hr,
  Html,
  Img,
  Preview,
  Section,
  Text,
} from '@react-email/components';

interface WelcomeEmailProps {
  name: string;
  loginUrl: string;
}

export function WelcomeEmail({ name, loginUrl }: WelcomeEmailProps) {
  return (
    <Html>
      <Head />
      <Preview>Welcome to Construx — your account is ready</Preview>
      <Body style={{ backgroundColor: '#f6f9fc', fontFamily: 'sans-serif' }}>
        <Container style={{ maxWidth: '600px', margin: '0 auto', padding: '20px' }}>
          <Heading style={{ color: '#1a1a2e', fontSize: '24px' }}>
            Welcome, {name}
          </Heading>
          <Text style={{ color: '#555', lineHeight: '1.6' }}>
            Your account is set up and ready. Click below to log in and get started.
          </Text>
          <Section style={{ textAlign: 'center', margin: '32px 0' }}>
            <Button
              href={loginUrl}
              style={{
                backgroundColor: '#F97316',
                color:           '#fff',
                padding:         '12px 24px',
                borderRadius:    '4px',
                fontSize:        '14px',
                fontWeight:      '600',
                textDecoration:  'none',
              }}
            >
              Log in to your account
            </Button>
          </Section>
          <Hr style={{ borderColor: '#e6e6e6' }} />
          <Text style={{ color: '#999', fontSize: '12px' }}>
            Construx Group · construxgroup.io
          </Text>
        </Container>
      </Body>
    </Html>
  );
}
```

Send it with `render` from `@react-email/render`:

```ts
import { render } from '@react-email/render';
import { WelcomeEmail } from '@/emails/WelcomeEmail';
import { resend } from '@/lib/resend';

async function sendWelcomeEmail(user: { name: string; email: string }) {
  const html = await render(
    WelcomeEmail({
      name:     user.name,
      loginUrl: `${process.env.NEXT_PUBLIC_SITE_URL}/login`,
    })
  );

  await resend.emails.send({
    from:    'Construx Group <hello@construxgroup.io>',
    to:      [user.email],
    subject: 'Welcome to Construx',
    html,
  });
}
```

## Batch sending

For notification digests or bulk sends, use the batch API:

```ts
const batch = users.map((user) => ({
  from:    'Construx Group <notifications@construxgroup.io>',
  to:      [user.email],
  subject: 'Your weekly digest',
  html:    render(DigestEmail({ user, items: user.digestItems })),
}));

// Up to 100 emails per batch request
const { data, error } = await resend.batch.send(batch);
```

## Webhooks for delivery events

Resend sends webhook events when emails are delivered, bounced, or complained about:

```ts
// app/api/webhooks/resend/route.ts
import { Webhook } from 'svix';

const webhook = new Webhook(process.env.RESEND_WEBHOOK_SECRET!);

export async function POST(req: Request) {
  const body = await req.text();
  const headers = Object.fromEntries(req.headers.entries());

  let event: ResendWebhookEvent;
  try {
    event = webhook.verify(body, headers) as ResendWebhookEvent;
  } catch {
    return Response.json({ error: 'Invalid signature' }, { status: 400 });
  }

  switch (event.type) {
    case 'email.delivered':
      await markEmailDelivered(event.data.email_id);
      break;
    case 'email.bounced':
      await handleBounce(event.data.to[0]);
      break;
    case 'email.complained':
      await unsubscribeUser(event.data.to[0]);
      break;
  }

  return Response.json({ received: true });
}
```

## Local development

The Resend SDK works in local development — emails are sent to real addresses. Use a test email address or Resend's test mode to avoid sending to real users during development:

```ts
// In development, send to yourself regardless of the recipient
const to = process.env.NODE_ENV === 'development'
  ? ['lewis@construxgroup.io']
  : [user.email];
```

Or use the email preview server from React Email:

```bash
npx react-email dev --dir emails --port 3001
```

This spins up a local preview at `localhost:3001` where you can see every template rendered without sending anything.

## Rate limits and quotas

Resend's free tier: 3,000 emails/month, 100/day. The Starter plan ($20/month) gives 50,000/month. For high-volume sends (millions/month), Resend supports dedicated IPs on higher plans — dedicated IPs let you warm your own reputation separate from shared infrastructure.

The key deliverability setup: verify your domain, set up DMARC in reporting mode first (`p=none; rua=mailto:...`), monitor the reports, then move to `p=quarantine` once you've confirmed no legitimate mail is being misidentified.
