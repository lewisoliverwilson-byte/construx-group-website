TypeScript types disappear at runtime. A type that says `{ id: number }` doesn't stop an API from returning `{ id: "abc" }`. Zod validates the shape of data at runtime and infers the TypeScript type from the schema — the two stay in sync automatically.

## Setup

```bash
npm install zod
```

## Basic schemas

```ts
import { z } from 'zod';

// Primitives
const Name    = z.string().min(1).max(100);
const Age     = z.number().int().min(0).max(150);
const Active  = z.boolean();
const Created = z.date();

// Parse (throws ZodError on failure)
Name.parse('Lewis');          // 'Lewis'
Name.parse('');               // throws

// Safe parse (returns { success, data } | { success: false, error })
const result = Name.safeParse('');
if (!result.success) {
  console.log(result.error.issues);
}
```

## Objects and inference

```ts
const UserSchema = z.object({
  id:        z.string().uuid(),
  email:     z.string().email(),
  name:      z.string().min(1),
  role:      z.enum(['admin', 'user', 'viewer']),
  plan:      z.enum(['free', 'pro', 'enterprise']).default('free'),
  createdAt: z.string().datetime(),
  metadata:  z.record(z.string()).optional(),
});

// Infer the TypeScript type — no duplication
type User = z.infer<typeof UserSchema>;
// { id: string; email: string; name: string; role: 'admin' | 'user' | 'viewer'; ... }
```

## Transforms and refinements

```ts
// Transform: parse then shape the output
const SlugSchema = z.string()
  .min(1)
  .transform((s) => s.toLowerCase().replace(/\s+/g, '-'));

SlugSchema.parse('Hello World');  // 'hello-world'

// Refine: add custom validation logic
const PasswordSchema = z.string()
  .min(8)
  .refine((s) => /[A-Z]/.test(s), { message: 'Must contain an uppercase letter' })
  .refine((s) => /[0-9]/.test(s), { message: 'Must contain a number' });

// Superrefine: access the context for multiple issues
const RangeSchema = z.object({ min: z.number(), max: z.number() })
  .superRefine(({ min, max }, ctx) => {
    if (min >= max) {
      ctx.addIssue({ code: 'custom', path: ['max'], message: 'max must be greater than min' });
    }
  });
```

## Arrays, unions, discriminated unions

```ts
const TagsSchema = z.array(z.string()).min(1).max(10);

// Union: one of several types
const IdSchema = z.union([z.string().uuid(), z.number().int().positive()]);

// Discriminated union: faster parsing via discriminant key
const EventSchema = z.discriminatedUnion('type', [
  z.object({ type: z.literal('click'),   x: z.number(), y: z.number() }),
  z.object({ type: z.literal('keydown'), key: z.string() }),
  z.object({ type: z.literal('scroll'),  delta: z.number() }),
]);

type Event = z.infer<typeof EventSchema>;
// Narrows correctly: if type === 'click', TypeScript knows x and y exist
```

## Validating API responses

```ts
const PostSchema = z.object({
  id:        z.number(),
  title:     z.string(),
  body:      z.string(),
  userId:    z.number(),
});

async function getPost(id: number) {
  const res  = await fetch(`/api/posts/${id}`);
  const json = await res.json();
  return PostSchema.parse(json);  // typed Post, throws if malformed
}
```

## Environment variable validation

```ts
// lib/env.ts — validate at startup, not on first use
const EnvSchema = z.object({
  DATABASE_URL:               z.string().url(),
  NEXTAUTH_SECRET:            z.string().min(32),
  UPSTASH_REDIS_REST_URL:     z.string().url(),
  UPSTASH_REDIS_REST_TOKEN:   z.string().min(1),
  NODE_ENV:                   z.enum(['development', 'production', 'test']).default('development'),
});

export const env = EnvSchema.parse(process.env);
```

If a required env var is missing, the server refuses to start with a clear error — not a cryptic runtime crash.

## Zod vs Yup vs Valibot

Zod: TypeScript-first, excellent inference, large ecosystem, `z.infer` is the standard pattern. Yup: older, less TypeScript-native, still common in Formik codebases. Valibot: smaller bundle (tree-shakeable), similar API, worth considering for edge runtimes where bundle size matters. For most TypeScript projects, Zod is the default.
