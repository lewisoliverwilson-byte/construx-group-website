Errors happen in production. Sentry is how you know which ones matter and what caused them.

## Install

```bash
npm install @sentry/nextjs

# Run the setup wizard
npx @sentry/wizard@latest -i nextjs
```

The wizard creates `sentry.client.config.ts`, `sentry.server.config.ts`, and adds instrumentation to `next.config.ts`.

## Configuration

```ts
// sentry.server.config.ts
import * as Sentry from '@sentry/nextjs';

Sentry.init({
  dsn:               process.env.NEXT_PUBLIC_SENTRY_DSN,
  environment:       process.env.NODE_ENV,
  release:           process.env.NEXT_PUBLIC_VERCEL_GIT_COMMIT_SHA,
  tracesSampleRate:  0.1,   // sample 10% of transactions
  profilesSampleRate: 0.1,
  integrations: [
    Sentry.prismaIntegration(),
    Sentry.captureConsoleIntegration({ levels: ['error', 'warn'] }),
  ],
});
```

```ts
// sentry.client.config.ts
import * as Sentry from '@sentry/nextjs';

Sentry.init({
  dsn:                    process.env.NEXT_PUBLIC_SENTRY_DSN,
  environment:            process.env.NODE_ENV,
  tracesSampleRate:       0.05,
  replaysSessionSampleRate: 0.01,   // 1% of sessions
  replaysOnErrorSampleRate: 1.0,    // 100% of sessions with errors
  integrations: [
    Sentry.replayIntegration({
      maskAllText:   true,
      blockAllMedia: false,
    }),
  ],
});
```

## Capturing errors with context

```ts
import * as Sentry from '@sentry/nextjs';

async function processPayment(userId: string, amount: number) {
  return Sentry.withScope((scope) => {
    scope.setUser({ id: userId });
    scope.setContext('payment', { amount, currency: 'GBP' });
    scope.setTag('flow', 'checkout');

    try {
      return stripe.charges.create({ amount, currency: 'gbp' });
    } catch (error) {
      Sentry.captureException(error);
      throw error;
    }
  });
}
```

## Performance: custom spans

```ts
import * as Sentry from '@sentry/nextjs';

async function generateReport(userId: string) {
  return Sentry.startSpan({ name: 'generate-report', op: 'task' }, async () => {
    const userData = await Sentry.startSpan(
      { name: 'fetch-user-data', op: 'db' },
      () => db.users.findUnique({ where: { id: userId } }),
    );

    const posts = await Sentry.startSpan(
      { name: 'fetch-posts', op: 'db' },
      () => db.posts.findMany({ where: { authorId: userId } }),
    );

    return buildReport(userData, posts);
  });
}
```

Spans appear in the Sentry trace view — you see exactly how long each step takes.

## Source maps

```ts
// next.config.ts
import { withSentryConfig } from '@sentry/nextjs';

const nextConfig = { /* your config */ };

export default withSentryConfig(nextConfig, {
  org:     'construx-group',
  project: 'website',
  silent:  true,
  // Upload source maps and delete them after upload
  sourcemaps: {
    disable: false,
  },
  // Hide source maps from the public bundle
  hideSourceMaps: true,
});
```

Source maps are uploaded to Sentry on each deploy. Stack traces in Sentry show the original TypeScript line — not the minified output. Delete the `.js.map` files from the public bundle so they are not accessible to end users.

## Alerts and issue routing

```yaml
# sentry rules (configured in UI or via API)
- name: "High error rate"
  conditions:
    - type: EventFrequencyCondition
      value: 100
      interval: "1h"
  actions:
    - type: SlackNotifyServiceAction
      workspace: construx
      channel: "#errors"
      tags: "environment,release"

- name: "New issue in production"
  conditions:
    - type: FirstSeenEventCondition
    - type: TagCondition
      key: environment
      value: production
  actions:
    - type: PagerDutyAction
      account: construx
      service: website-prod
```

## Sentry vs Datadog vs LogRocket

Sentry: best error grouping, strong source map support, session replays, reasonable pricing. Datadog: full observability platform (logs, APM, infrastructure), expensive, overkill for most web apps. LogRocket: session replay focused, less error monitoring. For a Next.js product: Sentry. If you are already paying for Datadog infrastructure monitoring: use Datadog APM to keep context in one place.
