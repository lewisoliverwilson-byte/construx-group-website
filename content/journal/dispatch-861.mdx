V8 isolates at the edge. Microsecond cold start. No containers.

## Basic Worker

```ts
// src/index.ts
import { Hono } from 'hono';
import { cors } from 'hono/cors';
import { logger } from 'hono/logger';

type Env = {
  ORDERS_KV:   KVNamespace;
  CACHE_TTL:   string;
  API_SECRET:  string;
};

const app = new Hono<{ Bindings: Env }>();

app.use('*', logger());
app.use('/api/*', cors({ origin: 'https://construxgroup.io' }));

app.get('/api/orders/:id', async (c) => {
  const id    = c.req.param('id');
  const env   = c.env;

  // Check KV cache first
  const cached = await env.ORDERS_KV.get(`order:${id}`, 'json');
  if (cached) return c.json(cached);

  // Fetch from origin
  const res = await fetch(`https://api.construxgroup.io/orders/${id}`, {
    headers: { Authorization: `Bearer ${env.API_SECRET}` },
  });

  if (!res.ok) return c.json({ error: 'Not found' }, 404);

  const order = await res.json();

  // Cache for 60s
  await env.ORDERS_KV.put(`order:${id}`, JSON.stringify(order), {
    expirationTtl: parseInt(env.CACHE_TTL) || 60,
  });

  return c.json(order);
});

export default app;
```

## Durable Objects — consistent state at the edge

```ts
// src/cart.ts — Durable Object for shopping cart
import { DurableObject } from 'cloudflare:workers';

export class Cart extends DurableObject {
  private items: Map<string, number> = new Map();

  async fetch(request: Request): Promise<Response> {
    const url  = new URL(request.url);
    const body = request.method === 'POST' ? await request.json<{ sku: string; qty: number }>() : null;

    if (url.pathname === '/add' && body) {
      const current = this.items.get(body.sku) ?? 0;
      this.items.set(body.sku, current + body.qty);
      // State is automatically persisted (no explicit storage call needed for Durable Objects)
      await this.ctx.storage.put('items', Object.fromEntries(this.items));
    }

    if (url.pathname === '/items') {
      return Response.json(Object.fromEntries(this.items));
    }

    return new Response('OK');
  }
}

// In the main Worker — route to the correct Durable Object by cart ID
app.post('/cart/:cartId/add', async (c) => {
  const cartId = c.req.param('cartId');
  const stub   = c.env.CART.get(c.env.CART.idFromName(cartId));
  return stub.fetch(c.req.raw);
});
```

## Fetch from origin with Smart Placement

```ts
// Smart Placement automatically runs the Worker closer to origin
// when the Worker makes many origin calls — reduces round-trip latency

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    // Parallel fetch from two origins
    const [orders, inventory] = await Promise.all([
      fetch(`https://api.construxgroup.io/orders`, {
        headers: { Authorization: `Bearer ${env.API_SECRET}` },
      }),
      fetch(`https://inventory.construxgroup.io/available`, {
        headers: { Authorization: `Bearer ${env.API_SECRET}` },
      }),
    ]);

    const [ordersData, inventoryData] = await Promise.all([
      orders.json(),
      inventory.json(),
    ]);

    return Response.json({ orders: ordersData, inventory: inventoryData });
  },
};
```

Workers vs Lambda@Edge: Lambda@Edge runs Node.js in containers deployed to CloudFront edge locations (~13 locations). Cold starts are 100-500ms. Workers run V8 isolates at 300+ locations with ~5ms startup (already warm — isolates are reused). Workers have a 128MB memory limit (vs 128-10240MB for Lambda) and a 10ms CPU time limit per request. Lambda@Edge supports any npm package; Workers have some restrictions (no native modules). For latency-sensitive edge logic at global scale, Workers. For complex compute with large memory requirements, Lambda.
