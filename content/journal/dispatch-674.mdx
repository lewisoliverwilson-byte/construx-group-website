Most backends are request/response: the client asks, the server answers. To get reactive data, you add WebSockets, polling, or a separate realtime service. Convex makes reactivity the default — every query function is automatically a live subscription. The client re-renders when the data changes.

## Setup

```bash
npm install convex
npx convex dev  # starts the local dev backend and deploys functions on save
```

## Schema

```ts
// convex/schema.ts
import { defineSchema, defineTable } from 'convex/server';
import { v }                         from 'convex/values';

export default defineSchema({
  posts: defineTable({
    title:     v.string(),
    content:   v.string(),
    authorId:  v.id('users'),
    published: v.boolean(),
    createdAt: v.number(),
  })
    .index('by_author',    ['authorId'])
    .index('by_published', ['published', 'createdAt']),

  users: defineTable({
    name:    v.string(),
    email:   v.string(),
    plan:    v.union(v.literal('free'), v.literal('pro')),
    tokenId: v.string(),
  })
    .index('by_token', ['tokenId']),
});
```

Types are inferred from the schema — no code generation step.

## Queries (reactive reads)

```ts
// convex/posts.ts
import { query } from './_generated/server';
import { v }     from 'convex/values';

// This query becomes a live subscription on the client automatically
export const getPublishedPosts = query({
  args:    {},
  handler: async (ctx) => {
    return ctx.db
      .query('posts')
      .withIndex('by_published', (q) => q.eq('published', true))
      .order('desc')
      .take(20);
  },
});

export const getPostById = query({
  args:    { id: v.id('posts') },
  handler: async (ctx, { id }) => {
    return ctx.db.get(id);
  },
});
```

## Mutations (writes)

```ts
// convex/posts.ts
import { mutation } from './_generated/server';
import { v }        from 'convex/values';

export const createPost = mutation({
  args: {
    title:   v.string(),
    content: v.string(),
  },
  handler: async (ctx, { title, content }) => {
    const identity = await ctx.auth.getUserIdentity();
    if (!identity) throw new Error('Unauthorized');

    const user = await ctx.db
      .query('users')
      .withIndex('by_token', (q) => q.eq('tokenId', identity.tokenIdentifier))
      .unique();

    if (!user) throw new Error('User not found');

    return ctx.db.insert('posts', {
      title,
      content,
      authorId:  user._id,
      published: false,
      createdAt: Date.now(),
    });
  },
});
```

## React client (live queries)

```tsx
// app/posts/page.tsx
'use client';

import { useQuery, useMutation } from 'convex/react';
import { api }                   from '@/convex/_generated/api';

export default function PostsPage() {
  // useQuery is a live subscription — re-renders when data changes
  const posts  = useQuery(api.posts.getPublishedPosts);
  const create = useMutation(api.posts.createPost);

  if (posts === undefined) return <div>Loading…</div>;

  return (
    <div>
      {posts.map((post) => (
        <div key={post._id}>{post.title}</div>
      ))}
      <button onClick={() => create({ title: 'New Post', content: '…' })}>
        Add Post
      </button>
    </div>
  );
}
```

When any other user creates or edits a post, every connected client re-renders automatically.

## Actions (side effects, external APIs)

```ts
// convex/emails.ts
import { action } from './_generated/server';
import { v }      from 'convex/values';
import { Resend } from 'resend';

// Actions can call external APIs, unlike queries and mutations
export const sendWelcomeEmail = action({
  args:    { userId: v.id('users') },
  handler: async (ctx, { userId }) => {
    const user = await ctx.runQuery(api.users.getById, { id: userId });
    const resend = new Resend(process.env.RESEND_API_KEY);
    await resend.emails.send({
      from:    'welcome@construxgroup.io',
      to:      user.email,
      subject: 'Welcome to Construx',
      html:    '<p>Thanks for signing up.</p>',
    });
  },
});
```

## Scheduled functions

```ts
// convex/crons.ts
import { cronJobs } from 'convex/server';
import { api }      from './_generated/api';

const crons = cronJobs();

crons.daily(
  'daily-digest',
  { hourUTC: 8, minuteUTC: 0 },
  api.emails.sendDailyDigest,
  {},
);

export default crons;
```

## Convex vs Supabase vs Firebase

Convex: TypeScript-first, reactivity built in, co-located server functions and schema. No SQL — its own query API. Supabase: Postgres, SQL, realtime via Postgres changes. Firebase: NoSQL, mature mobile SDKs, Google-backed. Convex is the best fit when you want end-to-end TypeScript and live queries without building a WebSocket layer. Supabase fits better when you need SQL or want to self-host.
