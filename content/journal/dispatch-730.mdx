Polling is a workaround. WebSockets are the real-time primitive. Here is how to use them in each environment.

## Bun native WebSocket

```ts
// server.ts
const server = Bun.serve({
  port: 3001,

  fetch(req, server) {
    const url = new URL(req.url);

    if (url.pathname === '/ws') {
      const upgraded = server.upgrade(req, {
        data: { userId: url.searchParams.get('userId') },
      });
      if (upgraded) return;
    }

    return new Response('Not found', { status: 404 });
  },

  websocket: {
    open(ws) {
      ws.subscribe(`user:${ws.data.userId}`);
      ws.send(JSON.stringify({ type: 'connected', userId: ws.data.userId }));
    },

    message(ws, message) {
      const data = JSON.parse(String(message));

      if (data.type === 'ping') {
        ws.send(JSON.stringify({ type: 'pong' }));
        return;
      }

      // Publish to a topic — all subscribers receive it
      server.publish(`user:${ws.data.userId}`, JSON.stringify(data));
    },

    close(ws, code, reason) {
      ws.unsubscribe(`user:${ws.data.userId}`);
    },
  },
});

// Send a message to a specific user from anywhere in the server
server.publish('user:lewis', JSON.stringify({ type: 'notification', text: 'New message' }));
```

## Hono WebSocket (Cloudflare Workers)

```ts
import { Hono }            from 'hono';
import { upgradeWebSocket } from 'hono/cloudflare-workers';

const app = new Hono();

app.get(
  '/ws',
  upgradeWebSocket((c) => ({
    onOpen(event, ws) {
      ws.send(JSON.stringify({ type: 'connected' }));
    },

    onMessage(event, ws) {
      const data = JSON.parse(event.data as string);
      ws.send(JSON.stringify({ echo: data }));
    },

    onClose() {
      console.log('Connection closed');
    },
  })),
);

export default app;
```

## Client-side

```ts
// src/lib/websocket.ts
type Message = { type: string; [key: string]: unknown };
type Handler = (msg: Message) => void;

class RealtimeClient {
  private ws:          WebSocket | null = null;
  private handlers:    Map<string, Handler[]> = new Map();
  private reconnectMs  = 1000;

  connect(url: string) {
    this.ws = new WebSocket(url);

    this.ws.onmessage = (event) => {
      const data: Message = JSON.parse(event.data);
      this.handlers.get(data.type)?.forEach((h) => h(data));
    };

    this.ws.onclose = () => {
      setTimeout(() => this.connect(url), this.reconnectMs);
      this.reconnectMs = Math.min(this.reconnectMs * 2, 30_000);
    };

    this.ws.onopen = () => {
      this.reconnectMs = 1000;
    };
  }

  on(type: string, handler: Handler) {
    if (!this.handlers.has(type)) this.handlers.set(type, []);
    this.handlers.get(type)!.push(handler);
  }

  send(msg: Message) {
    if (this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify(msg));
    }
  }
}

export const realtime = new RealtimeClient();
```

```tsx
// React hook
function useRealtime<T extends Message>(type: string, handler: (msg: T) => void) {
  useEffect(() => {
    realtime.on(type, handler as Handler);
    return () => { /* cleanup */ };
  }, [type, handler]);
}

// Usage
function NotificationBell() {
  const [count, setCount] = useState(0);

  useRealtime<{ type: 'notification'; text: string }>('notification', (msg) => {
    setCount((c) => c + 1);
    toast(msg.text);
  });

  return <button>🔔 {count}</button>;
}
```

## Architecture decision

Bun native WebSocket: simplest, fastest, no dependencies, Bun only. Hono upgradeWebSocket: works on Cloudflare Workers, Bun, and Deno. Socket.IO: rooms, namespaces, auto-reconnect, Redis adapter for horizontal scaling — worth the overhead for complex real-time features. Partykit: hosted WebSocket infra, Durable Objects under the hood, pay-per-connection. The 2030 default for a new project: Bun native if running on Bun, Hono upgradeWebSocket if running on Cloudflare Workers, Socket.IO if you need rooms and horizontal scaling.
