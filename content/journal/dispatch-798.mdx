Full analytics stack. Self-hostable. One SDK.

## Install

```bash
bun add posthog-js          # Browser
bun add posthog-node        # Server-side
```

## Browser setup

```ts
// app/providers.tsx
'use client';

import posthog            from 'posthog-js';
import { PostHogProvider } from 'posthog-js/react';
import { useEffect }      from 'react';

export function PHProvider({ children }: { children: React.ReactNode }) {
  useEffect(() => {
    posthog.init(process.env.NEXT_PUBLIC_POSTHOG_KEY!, {
      api_host:             process.env.NEXT_PUBLIC_POSTHOG_HOST,  // Self-hosted or app.posthog.com
      person_profiles:      'identified_only',
      capture_pageview:     false,  // Use router events instead
      capture_pageleave:    true,
      session_recording: {
        maskAllInputs:      true,
        maskInputOptions:   { password: true, creditCard: true },
      },
    });
  }, []);

  return <PostHogProvider client={posthog}>{children}</PostHogProvider>;
}
```

## Capture events

```ts
import { usePostHog } from 'posthog-js/react';

function CheckoutButton({ planId }: { planId: string }) {
  const posthog = usePostHog();

  const handleClick = () => {
    posthog.capture('checkout_started', {
      plan_id:      planId,
      source:       'pricing_page',
      experiment:   posthog.getFeatureFlag('pricing-v2') ? 'v2' : 'control',
    });

    router.push('/checkout');
  };

  return <button onClick={handleClick}>Get started</button>;
}
```

## Identify users

```ts
// After login — link events to a user identity
posthog.identify(user.id, {
  email:      user.email,
  name:       user.name,
  plan:       user.plan,
  created_at: user.createdAt,
});

// Group analytics — events attributed to an organization
posthog.group('company', user.orgId, {
  name:       user.org.name,
  plan:       user.org.plan,
  seat_count: user.org.memberCount,
});
```

## Server-side events (Node.js)

```ts
// lib/analytics.ts
import { PostHog } from 'posthog-node';

export const analytics = new PostHog(process.env.POSTHOG_KEY!, {
  host:        process.env.POSTHOG_HOST,
  flushAt:     20,   // Batch size
  flushInterval: 5000,  // Flush every 5s
});

// API route: POST /api/checkout/complete
export async function POST(req: Request) {
  const { userId, planId, amount } = await req.json();

  analytics.capture({
    distinctId:  userId,
    event:       'subscription_created',
    properties: {
      plan_id:  planId,
      amount,
      currency: 'GBP',
    },
  });

  return Response.json({ success: true });
}

// Shutdown hook — flush remaining events
process.on('SIGTERM', () => analytics.shutdown());
```

## Feature flags

```ts
// Check in server components
const isNewDashboard = await analytics.isFeatureEnabled('new-dashboard', userId);

// React hook
import { useFeatureFlagEnabled } from 'posthog-js/react';

function Dashboard() {
  const isNewDashboard = useFeatureFlagEnabled('new-dashboard');

  return isNewDashboard ? <NewDashboard /> : <OldDashboard />;
}
```

## A/B test

```ts
// PostHog dashboard → Experiments → Create experiment
// Variants: control (50%), treatment (50%)
// Goal: checkout_started events

function PricingSection() {
  const variant = useFeatureFlagVariantKey('pricing-v2');

  if (variant === 'treatment') {
    return <PricingV2 />;  // New annual-first pricing
  }

  return <PricingControl />;  // Original monthly-first
}
```

PostHog automatically tracks conversion rates per variant, calculates statistical significance, and recommends when to end the experiment.

PostHog vs Mixpanel vs Amplitude: Mixpanel and Amplitude are SaaS-only, priced per event, US data residency. PostHog is open-source, self-hostable, and includes session recording + feature flags that Mixpanel/Amplitude charge extra for. The tradeoff: PostHog self-hosting requires infrastructure to maintain. The Construx default: PostHog cloud (EU region) for all products. Self-host only if a customer's data sovereignty requirements demand it.
